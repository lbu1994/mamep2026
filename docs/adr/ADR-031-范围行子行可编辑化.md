# ADR-031：范围行子行可编辑化（Name/Data/Type/Scale/Comment 可编辑 + 持久化）

- 状态：已确认（**已实施完成**，2026-08-27）
- 日期：2026-08-27
- 决策来源：用户任务（在 ADR-030 多寄存器范围行基础上，要求展开后的子行可编辑：
  Name / Data（与父行同步）/ Type / Scale（在该行生效）/ Comment 可编辑，其余列不可编辑或
  功能不可生效；以上信息需持久化、重启可恢复）

## 背景

- ADR-030 范围行（`registerCount>1`）经 antd Table 树形数据展开为每寄存器一子行；**当前子行是
  `packages/ui/src/tree-rows.ts` 派生的虚拟只读行**（`__virtualChild` 标记，不落 store、不持久化），
  仅 Register 列（实际地址）与 Data 列（格式化值）只读展示，其余列渲染 null。
- 数据模型：`RegisterRow.registerValues: RawRegisterValue[] | null` 是单一事实源（长度=registerCount），
  `cellText` 是父行组合文本，`dataType` 每行仅一个（Type 进制列 + Scale 列映射回单一 dataType）。
- 组合语义分两类：HEX/Binary/String 为「逐寄存器独立」；Unsigned/Signed/带 Scale 在
  registerCount=2/4 时为**跨寄存器组合的单个数值**（32/64 位，`formatRawValues`/`parseCompositeText`
  组合/拆解）——这是子行独立 Type/Data 语义必须对齐的约束。

## 决策（5 项，用户确认）

1. **子行元数据模型**：父行 `RegisterRow` 新增 `registers: RegisterSubRowMeta[] | null`
   （`{name, comment, dataType}`，长度=registerCount；count=1 或老数据为 null）；`registerValues`
   保持原始值单一事实源。子行 = `registers[i]`（元数据）+ `registerValues[i]`（值）。
2. **父行与子行 Type/Scale 关系**：父行 Type/Scale 保留（继续决定父行组合文本的解析/格式化与
   读写组帧）；子行 Type/Scale 独立、仅影响该子行单个 16 位寄存器的显示与编辑解析；
   两者经 registerValues 一致（原始值是真源），协议行为零改动。
3. **范围变化保留策略**：`commitAddress` 时 registers 按索引保留/截断/补齐（缺省继承父行
   dataType）；`registerValues` 维持 ADR-030 现状（范围变化即清空，防协议错位）。
4. **写路径不变**：FC0x10 仍按父行 `cellText` + 父行 `dataType` 组合解析（`parseCompositeText`）；
   子行编辑后自动重算父行 `cellText`（`formatRawValues`），保证写路径一致性。
5. **读/轮询/写后回读**：只覆盖值（registerValues），不覆盖子行 Name/Comment/Type。

## 同步语义（实现要点）

- **子行 → 父行**：`commitChildCellText` 用子行自身 dataType 走 `parseCellText` 解析单个 16 位
  原始值 → 写 `registerValues[i]` → 重算父行 `cellText = formatRawValues(values, 父行 dataType)`；
  registerValues 为 null 时先由父行 `cellText`（`parseCompositeText`）派生基准数组，派生失败全 0
  填充，再置 index。
- **父行/外部 → 子行**：父行 Data 提交、手动读、轮询、写后回读更新 `registerValues` 后，各子行
  按自身 dataType 经 `formatRawValue` 重新格式化展示。
- 注意：子行编辑后父行 `cellText` 会被规范化（`formatRawValues`），符合 §15.1 单一当前值模型。

## 实施（分层落地）

- **domain**（`packages/domain`）：新增 `RegisterSubRowMeta` 接口 + `createRegisterSubRowMeta(s)`
  辅助；`RegisterRow.registers` 字段；`createEmptyRow` 置 null；`workspaceSchemaVersion` 升 4。
- **register-table**（`packages/register-table`）：新增 `child-register.ts`——`commitChildCellText`、
  `setChildMeta`、`childDataType`（缺省回退父行）、`ensureRegisters`、`resizeRegisters`
  （按索引保留/截断/补齐，范围未变原引用返回）；`address.ts` `commitAddress` 接 `resizeRegisters`；
  `row-clipboard.ts` 粘贴范围行时初始化 registers（剪贴板不携带子行元数据）。
- **workspace**（`packages/workspace`）：rowSchema 增 `registers`（nullable + `.default(null)`）；
  新增 **v3→v4 迁移**（范围行补齐 `{name:"", comment:"", dataType: 父行 dataType}`，保证迁移后展示
  与迁移前一致；单寄存器行 null）；迁移链 v1→v2→v3→v4 连续。
- **platform-api**（`packages/platform-api`）：`registerRowPayloadSchema` 增 `registers`（nullable +
  default null）+ `toRegisterRowPayload` / `registerRowFromPayload` 双向映射；**不新增 kind**。
- **ui**（`packages/ui`）：`tree-rows.ts` 子行携带自身 name/comment/dataType 并按自身 Type 格式化；
  `app-store` 新增 `commitChildCellText` / `setChildMeta`（定位父行 → 领域函数 → updateRow）；
  `RegisterTable.tsx` 子行 **Name/Data/Type/Scale/Comment 五列可编辑**（Name/Comment/Data 复用
  `EditableCellValue`，Type/Scale 复用 antd `Select`），其余列（No/TM/WP/Read/Write/Register/
  拖拽/多选/右键菜单）维持不可用。

## 验证

- 单测全绿：domain 50 / platform-api 44 / register-table 113 / workspace 36 / ui 196 / electron 58 /
  vscode-extension 50 / application 27 / web 60 / data-conversion 71 / communication 93 /
  protocol-modbus 44 等；typecheck 23/23、lint EXIT=0。
- 全仓 `pnpm test` 23/23 tasks（含 e2e-web 78 / e2e-electron 18 / e2e-vscode）无回归。
- e2e-web `range-row.spec.ts` 新增「范围行子行可编辑化：Name/Data/Type/Scale/Comment 编辑 +
  重启恢复」用例，6/6 全绿。
- 浏览器冒烟（mockTransport）：子行五列可编辑、其余列禁用；子行 Data 编辑 → 父行
  registerValues + 组合文本同步（`00AB` → 父行 `00AB 0000`；子行 `300` → `00AB 012C`）；
  子行 Type 独立生效（hex→unsigned 重解释 + Scale 启用）；刷新后 IndexedDB 全还原。

## 已知说明与后续

- 子行 Data 校验失败：静默回退（复用父行错误展示，不扩展子行独立错误态）；父行 cellText 规范化
  行为见「同步语义」。
- 本期不做：子行独立 WP/Read/Write/地址/拖拽/多选/右键菜单（维持 ADR-030 决策 4「仅父行写可用」）；
  剪贴板携带子行元数据；`communication` 零改动。
- e2e 踩坑：① reload 前须 `waitForTimeout(1000)` 等 IndexedDB 自动保存落盘（防抖）；② antd Select
  的 combobox 自身文本不含选中项，断言子行 Type 持久化用「Scale 是否可用」或 Data 显示文本
  （"300" vs hex "012C" 自证）。
