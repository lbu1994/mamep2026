## 背景

- ADR-042 已落地「用户自定义主题主色」：Settings 弹窗浅/深两个 antd `ColorPicker` + 重置按钮，持久化
  `workspace.preferences.themePrimary: { light: string; dark: string } | null`（workspace schema v5→v6 时引入），
  装配链 = 插件 theme 贡献（最高优先、自动应用）→ 用户设置 → 默认 `buildTheme`；用户色不满足白字 AA 时回退默认 + warning。
- 问题：任意取色（ColorPicker）超出「主题色 = 少量受控预设」的产品语义；插件 theme 贡献「启用即整站变色」与
  「用户按需选用」矛盾；example-panel 靛蓝开箱即覆盖全局。
- 本 ADR 只逆转**主题色部分**：删除任意取色 UI/测试；内置仅「Ant Design 默认蓝」一个选项；插件贡献改为
  **注册可选主题色**（一个或多个），由用户在 Settings 选择器中选用。

## 决策（2026-09-02 用户确认，D1–D7）

### 1. 内置默认蓝 = Ant Design 默认色（D1）

- `buildTheme(dark)` 主色改为 **浅 `#1677ff` / 暗 `#1668dc`**（字面 antd 默认；暗色 `#1668dc` 即 antd 暗色默认主色），
  `colorLink` 同步为同色（浅 `#1677ff` / 暗 `#1668dc`），hover/active 维持既有 antd 派生值。
- 接受浅色主按钮白字对比度由 ≈5.7:1 降至 ≈4.1:1（antd 默认水平）：主色仅用于关键操作/选中态，风险可控；
  内置默认蓝**不参与** AA 白字守卫（D6）。
- `apps/web/src/index.css` 的 `--mamep-brand-primary` / `--mamep-focus-ring` **默认兜底值**同步为 `#1677ff`（浅），
  暗色保持 `#1668dc` / `#6ba1ff`；运行时仍由主题装配 effect 覆盖（ADR-042 注入机制不变，D7）。

### 2. 插件 theme 贡献 = 注册可选主题色，不再自动应用（D2 / D5）

- `theme` 贡献点 payload 扩展为 **多色数组**（D5）：

  > 2026-09-03 修订：`colorPrimary` 改为**单一明亮模式主色**（`string`），删除 `colorLink`；
  > 链接色默认跟随主色，暗色主色 / hover / active 由 antd 色彩算法自动派生（方案 A）。

  ```ts
  theme: {
    colors: Array<{
      id: string; // 色板内唯一
      titleKey: string; // 显示名（i18n 键）
      colorPrimary: string; // 单一明亮模式主色（种子）；链接色跟随主色，暗色/hover/active 由 antd 算法派生
    }>;
  }
  ```

- 插件贡献仅作为 Settings「主题色」选择器的**可选预设**；装配链删除「插件自动应用层」
  → 装配链 = 用户所选预设（持久化）→ 默认 `buildTheme`。
- 禁用/卸载插件后其颜色从选项消失；已持久化选中该色 → 解析不到 → 回退默认蓝。
- 允许已安装第三方插件注册颜色（纯数据、无执行面，ADR-044 隔离边界不变）。

### 3. 持久化 = 预设 ID + schema v7→v8 迁移（D3）

- `workspace.preferences.themePrimary` 改为 `string | null`：
  - `null` = 内置默认蓝；
  - `<pluginId>:<colorId>` = 插件注册色（完整预设 ID）。
- **v7→v8 迁移**：旧 `{ light, dark }` 任意 HEX 无预设可映射 → 一律置 `null`（默认蓝）；`null` 保持。
- `workspaceSchemaVersion` 7→8；serializeWorkspace / parseWorkspace / exchange.ts 自动跟进（字段直通）。

### 4. Settings 选择器 UI（D4）

- 删除两行 `ColorPicker` 与「重置」按钮；改为**单个 antd `Select`**：
  - 选项 1（恒在）：内置默认蓝（i18n `settings.themeColorDefault`）；
  - 选项 2+：各启用插件注册色（label = 插件 titleKey 的 i18n + 色块预览，swatch 取 `colorPrimary`，2026-09-03 修订）。
  - 选择值 = `themePrimary ?? "default"`（哨兵常量 `DEFAULT_THEME_COLOR_ID`，不持久化）。
  - 选中「默认蓝」→ `setThemePrimary(null)`；选中插件色 → `setThemePrimary("<pluginId>:<colorId>")`。
- 预设自带浅/深两态，不再按浅/深分行各设；删除独立重置按钮（选回默认即等价重置）。
- 复用 antd v6 既有 `Select`，不引新库。

### 5. 对比度守卫（D6）

- **移除**用户主题色的 AA 白字守卫与 `themeColorContrastWarning` 提示（用户确认 D6 移除）：
  插件色按注册值直接应用，不做运行时对比度校验；`ui-theme/contrast.ts` 工具与静态脚本保留（其他消费方/工具用途）。

### 6. 范围边界（D7）

- 零改动：Address Adjust（ADR-042 同批另一半）、VSCode `mapVscodeTheme` 主色存活/派生跟随取舍、`--mamep-*`
  CSS 变量的**装配注入机制**、能力矩阵、HostMessage v1、协议层/调度器、三端宿主层（装配与持久化 Renderer 共享）。

## 影响面

- 删除：Settings 两行 ColorPicker + 重置、`setThemePrimary` 对象形态、AA 校验/警告 effect、
  `settings.themeColorLight/Dark/Reset/ContrastWarning` i18n 键、`collectThemeConfig`（自动应用消费方）、
  `tests/e2e-web/tests/theme-color.spec.ts`。
- 新增：`theme` 贡献点 `colors[]` schema（`THEME_COLOR_PRESET_SCHEMA`）、
  `buildThemeColorOptions` / `findThemeColorOption` / `themeConfigForColorOption`（ui theme-contributions 新消费方）、
  Settings Select、`settings.themeColorDefault`、`plugins.exampleThemeColor`（example-panel 靛蓝演示键）、
  迁移 v7→v8、e2e `theme-color-presets.spec.ts`。
- 更新：`base.ts` 默认蓝、index.css 兜底值、example-panel theme 贡献（数组形态）、
  `plugin-contributions.spec.ts`（插件色不再自动应用）、app-store/workspace/plugin-api 相关测试。

## 测试

- 单测：workspace（v7→v8 迁移 + 链完整性）、plugin-api（colors 数组校验/非法拒绝）、ui
  （theme-contributions 新消费方、app-store 预设 ID setter）、example-panel（数组贡献断言）。
- e2e-web：`theme-color-presets.spec.ts`（默认蓝 / 插件色选项出现与选中 / token+CSS 变量同步 / reload 持久化 /

## 已知限制 / 后续

- 插件色选择与插件启停强绑定：禁用/卸载后已选色回退默认（不做「颜色残留」缓存）。
- `settings.themeColorContrastWarning` 语义废弃；若未来需插件色 AA 提示可再 ADR。
