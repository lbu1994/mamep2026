# ADR-046：浏览器兼容性检测

- 日期：2026-09-02
- 状态：已确认
- 关联：PRD §8.3（P1）、PRD §15.7 兼容性、TECH_DESIGN §40.2 浏览器环境

## 背景

「浏览器兼容性检测」为 PRD §8.3 P1 待办。此前已有零散防护（`BrowserAppHost.supportsWebSerial()`、
连接弹窗 `unsupportedWebSerial` 警告、`WEB_SERIAL_UNSUPPORTED` 能力错误），但未达到
PRD §15.7 浏览器五项要求：

1. 在进入连接流程前完成能力检测；
2. 明确提示不支持的能力；
3. 提供可行的替代方案说明；
4. 不显示虚假的连接成功状态；
5. 仍允许用户查看界面或已有工作区数据，但不得执行不可用的串口操作。

## 方案

分层落地，能力矩阵（`PlatformCapabilities`）**不变**——本次是运行时环境检测，不是平台声明。

### 1. 检测模型（domain）

新增 `BrowserCompatibility` / `BrowserCompatibilityIssue`（`web-serial-missing` /
`insecure-context`）+ `FULL_BROWSER_COMPATIBILITY`，纯数据类型。

### 2. 检测实现（platform-web）

`detectBrowserCompatibility(env)`：注入式纯函数（`serial` + `isSecureContext`），
`detectFromBrowser()` 从真实 `window/navigator` 读取；不直接访问 DOM，可单测。

### 3. Host 契约（ui）

`AppHost.browserCompatibility: BrowserCompatibility | null`；桌面端（Electron/VSCode）为
`null`（串口能力经能力矩阵声明，不走浏览器兼容性提示）。

### 4. UI

- **启动横幅** `BrowserCompatibilityBanner`（`.mamep-body` 顶部，antd `Alert banner`）：
  明确提示 + 替代方案（Chromium 内核浏览器或 Electron/VSCode 桌面版；工作区仍可查看）；
  桌面端 / mock 传输 / 全部满足时不渲染。
- **连接弹窗**：警告文案增强（含安全上下文提示 + 替代方案）；检测失败（非 mock、非
  enumerated、`supportsWebSerial=false`）时**禁用 CONNECT**（§15.7 第 4/5 条）。

### 5. 装配（apps/web）

`BrowserAppHost` 构造时检测；`compatibilityEnv` 可注入（单测/e2e）。
dev 门控 `?compatMiss=1`（沿用 `?mockTransport=1` 先例）：强制检测输入为「无 Web Serial」，
供 e2e 确定性触发。

## 决策点

1. **检测失败禁用 CONNECT**（替代原先点击后报 `WEB_SERIAL_UNSUPPORTED`）——依据 §15.7。
2. **替代方案文案**：统一「Chromium 内核浏览器（Chrome/Edge），或 Electron/VSCode 桌面版；
   工作区仍可查看」。
3. **dev 门控**：`?compatMiss=1` 仅 `import.meta.env.DEV`（与 mockTransport 一致），生产不生效。
4. **能力矩阵不变**：运行时环境检测不进入平台能力声明。
5. **桌面端 null**：Electron/VSCode 不显示浏览器兼容性提示。

## 测试

- platform-web：`browser-compatibility.test.ts`（4 用例：全满足 / 缺 serial / 非安全上下文 / 双缺）。
- apps/web：`app-host.test.ts` 追加（注入环境 ×4：缺失/完整/非安全/mock）。
- ui：`BrowserCompatibilityBanner.test.tsx`（3 用例）+ `ConnectionSettingsModal.compat.test.tsx`
  （3 用例：禁用+警告 / 支持环境 / 安全上下文提示）+ 共享桩 `test/make-app-host.ts`。
- e2e-web：`browser-compat.spec.ts`（`?compatMiss=1`：横幅 + 弹窗警告 + CONNECT 禁用 +
  工作区可查看 + 无 console 错误；mock 基线：无横幅）。

## 影响面

- 三端 host 接口新增只读字段（桌面端 `null`）；无协议 / HostMessage v1 / 持久化变更。
- 既有测试 fixtures：直接构造 `AppHost` 的桩补 `browserCompatibility`（`as unknown as AppHost`
  桩不受影响）。

## 已知边界

- `navigator.serial` 存在但授权/设备访问失败（用户取消、权限拒绝）仍由运行时错误兜底
  （`SERIAL_REQUEST_FAILED` / `WEB_SERIAL_UNSUPPORTED`），不在本检测范围。
- 检测不改变能力矩阵；浏览器 TCP 红线不变（PRD §8.6）。
