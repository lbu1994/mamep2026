# ADR-037：更完整的键盘操作（快捷键注册表 + 两级分发 + Help 总览）

- 状态：已确认
- 日期：2026-08-30
- 决策来源：用户任务（PRD §8.3 P1「更完整的键盘操作」；4 项用户决策：全量覆盖 /
  扩展现有 Help 弹窗 / 轻量表格导航（方向键移动选中行，不做单元格级）/ 替代组合三端一致）

## 背景

- **PRD §8.3 P1**：更完整的键盘操作（README 分阶段 ToDoList 未勾选项）。
- **PRD §15.6 可访问性（建议）**：所有核心功能键盘可达、清晰键盘焦点、表格支持方向键 /
  Tab / Shift+Tab 导航、图标按钮有辅助文本、动态数据不抢焦点、对话框关闭后恢复焦点等。
- **docs/AGENTS.md §25.5**：键盘可完成核心任务；焦点状态清晰；虚拟化不破坏基本键盘导航。
- **既有资产**：
  - 行编辑快捷键（ADR-015）：`Alt+↑/↓` 上移/下移、`Delete` 删除、`Ctrl+C/X/V` 复制/剪切/粘贴、
    `Ctrl+I` 插入；撤销/重做（ADR-032）：`Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y`。集中在
    `packages/ui/src/components/RegisterTable.tsx` 的 `handleGlobalKeyDown`（窗口级 `keydown` +
    `keydownRef` 防陈旧闭包 + 文本控件守卫）。
  - 应用级操作（连接/断开、全表读、标签页、设置/帮助/插件、导入导出、主题等）此前无快捷键，
    全部依赖鼠标；MamepApp 无全局 keydown。
  - 帮助弹窗已存在（`topbar.help`，仅展示 about 文案）。
  - `WorkspaceFileActions` 内联导入/导出逻辑；`ReadCell`/`WriteCell` 内联单行读/写逻辑。

## 决策

1. **分层与架构**：
   - 纯 UI 交互与快捷键调度只在 `packages/ui`；领域逻辑（行编辑命令、撤销栈、读/写/轮询编排）
     一律走既有领域层（`packages/register-table`、`packages/application` 等），UI 不直接访问
     串口/TCP/文件系统（红线不破）。
   - **快捷键注册表单一事实源**：`packages/ui/src/keyboard/shortcuts.ts`（`ShortcutDef`：
     `id/scope/combo/comboLabel`；i18n 文案键派生 `keyboard.<id>`，避免双份维护漂移）。
     帮助弹窗与两级分发共用本表；单测断言无重复 combo、不占用浏览器/系统保留键、别名指向
     有效 id、i18n 文案齐全。
   - **两级分发**：
     - App 级：`keyboard/useGlobalShortcuts.ts`（新 hook）+ `components/AppShortcutLayer.tsx`
       （渲染在 MamepApp 的 `<AntApp>` 内，动作经 store/宿主直达，导入导出复用
       `useWorkspaceTransfer`）；
     - 表格级：`RegisterTable.handleGlobalKeyDown` 扩展（沿用 `keydownRef` 窗口监听模式，
       作用于活动表/选中行）。
2. **快捷键映射表（用户已确认）**：
   - App 级：`Ctrl+,` 设置 / `Ctrl+Enter` 连接·断开 / `Ctrl+/`、`?` 帮助（`?` 为别名）/
     `Ctrl+[`·`Ctrl+]` 上一·下一标签 / `Ctrl+Alt+N` 新建表 / `Ctrl+Alt+W` 关闭当前标签 /
     `Ctrl+Shift+S` 导出工作区 / `Ctrl+Alt+O` 导入工作区 / `Ctrl+Alt+T` 主题浅深切换 /
     `Ctrl+Alt+L` 展开并聚焦通信日志页签。
   - 表格级：`F9` 全表读（运行中再按 = 取消）/ `F8` 读选中行 / `Ctrl+Shift+Enter` 写选中行 /
     `Alt+P` 切换选中行轮询 / `↑`·`↓` 移动选中行（替换单选，焦点在表格体且非编辑态）/
     `Ctrl+Alt+R` 恢复列布局。
   - **保留既有**：`Alt+↑/↓`、`Delete`、`Ctrl+C/X/V/I`、`Ctrl+Z/Y/Shift+Z`、`Escape`、
     单元格 `Enter`/`Space` 编辑、antd `Tabs`/`Menu` 原生方向键语义，行为零变化。
   - **键位约束**：规避浏览器/系统保留组合（`Ctrl+W/T/N/R`、`Ctrl+Tab`、`Ctrl+1..9`、`F5/F12`、
     `Alt+←/→` 等），macOS 用 `metaKey`（沿用 `mod = ctrlKey || metaKey` 惯例）；`matchesShortcut`
     严格精确匹配修饰键（未声明的修饰键必须为空），保证 `Ctrl+Enter` 与 `Ctrl+Shift+Enter` 可区分。
3. **守卫（`keyboard/guards.ts`，app 级与表格级共用）**：
   - `isTextInputTarget`：焦点在文本类控件（输入/文本域/下拉/可编辑单元格 wrap/contenteditable）
     时不拦截快捷键（与 RegisterTable 既有守卫语义一致，selector 抽取共享）；
   - `isArrowNavigationBlocked`：方向键导航专用守卫——焦点在 `.ant-table` 体内、且不在真正编辑
     文本的控件内才允许 `↑/↓` 移动选中行（工具栏控件不被劫持；复选框聚焦可导航）；
   - `isAnyModalOpen`：任一弹窗打开（连接/设置/插件/帮助/导入预览/删除确认/批量关闭确认）时
     两级快捷键全部抑制，避免 `Ctrl+Enter` 与连接表单提交等冲突。
4. **帮助入口 = 扩展现有 Help 弹窗**：`helpModalOpen` 迁入 app-store（与其他弹窗同模式，
   便于快捷键弹窗抑制）；Help 弹窗新增「键盘快捷键」区块（`KeyboardShortcutsTable`：注册表
   驱动、按 app/table 分组、antd `Table size="small"` + 自写 `<kbd>` 风格 `ShortcutKey` 组件，
   antd v6 无内置 Kbd）；`Ctrl+/` 与 `?` 打开。i18n 双语 `keyboard.*`（en 定义、zh 补齐，
   `TranslationResources` 类型约束）。
5. **逻辑抽取（避免按钮与快捷键两处复制漂移）**：
   - `row-io.ts`：`readRowById` / `writeRowById` 统一单行读/写（请求 → 结果 → 状态点/回读覆盖/
     消息），`ReadCell`/`WriteCell`（按钮路径）与 `F8`/`Ctrl+Shift+Enter`（快捷键路径）共用；
   - `workspace-transfer.ts`：`useWorkspaceTransfer` 统一导入/导出（序列化/解析/落盘/提示），
     `WorkspaceFileActions`（Settings 按钮）与 `Ctrl+Shift+S`/`Ctrl+Alt+O` 共用，浏览器端隐藏
     `<input type="file">` 由两处各自渲染（AppShortcutLayer 亦渲染一份）。
6. **可访问性（§15.6/§25.5）**：核心操作键盘可达（专属快捷键或 Tab/Enter/Space 原生）；
   焦点可见（antd 既有 focus-visible）；弹窗关闭后焦点恢复（antd Modal 内置）；动态数据不抢
   焦点（不新增 focus 抢夺逻辑）；虚拟化（`Listy`）不破坏键盘导航（沿用 Tab 顺序）。
7. **测试与验证**：注册表/守卫/hook 纯单测（jsdom）+ `RegisterTable`/`MamepApp` 键盘用例
   （补齐 `handleGlobalKeyDown` 此前无单测的空白）+ e2e-web 新 `keyboard.spec.ts`
   （mockTransport，覆盖 `Ctrl+/`、`Ctrl+,`、`Ctrl+Enter`、`F9`、`Ctrl+[`/`Ctrl+]`、`↑/↓`+`Alt+P`、
   全程无 console 错误）。

## 范围边界

- **包含**：上述全部。
- **排除（已确认）**：单元格级方向键导航（轻量方案）；自定义快捷键重绑 UI（无需求）；
  快捷键持久化/配置（无需求）；`Shift+↑/↓` 键盘范围多选（antd rowSelection 无键盘扩展内置）。
- **其余操作经 Tab 原生可达（不设专属快捷键）**：日志 Copy/Export/Clear、Trace Play/Stop/Save、
  语言切换、插件管理、重置工作区、右键菜单项、侧边栏等——补齐/维持 tabIndex 与 aria-label。

## 已知限制

- **macOS F 键**：`F8`/`F9` 在 macOS 浏览器需按 `Fn`；帮助弹窗已列出按键，未做平台差异提示。
- **`Ctrl+Alt+*` 组合**：Windows 下个别输入法可能占用 `Ctrl+Alt` 组合，属第三方环境行为，
  不做规避（已记录）。
- **e2e 定位器**：antd Modal 内 `getByRole("heading")` 的可访问性树匹配不稳定，e2e 改用类名
  定位断言（功能等价、稳定性优先）。
