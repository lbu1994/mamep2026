## 1. 非连续读取存储寄存器（功能码 67 + 辅助功能码 010D）

使用功能码 67 (Hex.) 和辅助功能码 **010D (Hex.)**，从指定的寄存器读取**最多 120 个数据**。读取对象的存储寄存器编号可以分别指定。

### 1.1 帧结构

| 方向         | 帧结构（字节序均为大端）                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| 指令         | 从站地址(1) + 功能码 `67`(1) + 辅助功能码 `01 0D`(2) + 数据个数(2) + 存储寄存器编号 ×N(2N) + CRC-16(2) |
| 响应（正常） | 从站地址(1) + 功能码 `67`(1) + 辅助功能码 `01 0D`(2) + 字节数(2) + 数据 ×N(2N) + CRC-16(2)             |
| 响应（故障） | 从站地址(1) + 功能码 `E7`(1) + 错误代码(1) + CRC-16(2)                                                 |

- 指令「数据个数」= 要读取的存储寄存器个数（范围 1~120）；响应「字节数」= 数据个数 × 2。
- 异常响应功能码 = 功能码 | 0x80 = `67 | 0x80 = E7`（与 Modbus 异常约定一致）。

### 1.2 示例（手册表 6.11）：从从站 1 读取频率指令与转矩限制指令

- `0024H`：U1-01［频率指令］= 60.00 Hz（6000 = 1770H）
- `0028H`：U1-09［转矩指令］= 100.0%（1000 = 03E8H）

**指令（12 字节）**：完整字节 `01 67 01 0D 00 02 00 24 00 28 8B 29`

| 字节 | 内容                        | 设定数据(Hex.) |
| ---- | --------------------------- | -------------- |
| 0    | 从站地址                    | 01             |
| 1    | 功能码                      | 67             |
| 2    | 辅助功能码（高位）          | 01             |
| 3    | 辅助功能码（低位）          | 0D             |
| 4    | 数据个数（高位）            | 00             |
| 5    | 数据个数（低位）            | 02             |
| 6    | 存储寄存器 1 的编号（高位） | 00             |
| 7    | 存储寄存器 1 的编号（低位） | 24             |
| 8    | 存储寄存器 2 的编号（高位） | 00             |
| 9    | 存储寄存器 2 的编号（低位） | 28             |
| 10   | CRC-16（高位）              | 8B             |
| 11   | CRC-16（低位）              | 29             |

**响应（正常，12 字节）**：完整字节 `01 67 01 0D 00 04 17 70 03 E8 47 ED`

| 字节 | 内容                            | 设定数据(Hex.) |
| ---- | ------------------------------- | -------------- |
| 0    | 从站地址                        | 01             |
| 1    | 功能码                          | 67             |
| 2    | 辅助功能码（高位）              | 01             |
| 3    | 辅助功能码（低位）              | 0D             |
| 4    | 字节数（高位）                  | 00             |
| 5    | 字节数（低位）                  | 04             |
| 6    | 指定存储寄存器 1 的数据（高位） | 17             |
| 7    | 指定存储寄存器 1 的数据（低位） | 70             |
| 8    | 指定存储寄存器 2 的数据（高位） | 03             |
| 9    | 指定存储寄存器 2 的数据（低位） | E8             |
| 10   | CRC-16（高位）                  | 47             |
| 11   | CRC-16（低位）                  | ED             |

**响应（故障，5 字节）**：完整字节 `01 E7 02 EA 31`

| 字节 | 内容           | 设定数据(Hex.) |
| ---- | -------------- | -------------- |
| 0    | 从站地址       | 01             |
| 1    | 功能码         | E7             |
| 2    | 错误代码       | 02             |
| 3    | CRC-16（高位） | EA             |
| 4    | CRC-16（低位） | 31             |

## 2. 非连续写入存储寄存器（功能码 67 + 辅助功能码 010E）

使用功能码 67 (Hex.) 和辅助功能码 **010E (Hex.)**，向指定的存储寄存器写入数据。写入个数上限 **60**（表 6.20 错误码 03 的说明）。

> 通过 H5-11［通信的 ENTER 功能选择］的设定，使用写入指令改写参数值时，需要保存变更内容且使该内容有效的**确定指令**（详见 §3）。

### 2.1 帧结构

| 方向         | 帧结构（字节序均为大端）                                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 指令         | 从站地址(1) + 功能码 `67`(1) + 辅助功能码 `01 0E`(2) + 数据个数(2) + 字节数(2) + （存储寄存器编号(2) + 数据(2)）×N + CRC-16(2) |
| 响应（正常） | 从站地址(1) + 功能码 `67`(1) + 辅助功能码 `01 0E`(2) + 数据个数(2) + CRC-16(2)                                                 |
| 响应（故障） | 从站地址(1) + 功能码 `E7`(1) + 错误代码(1) + CRC-16(2)                                                                         |

- 指令「数据个数」= 要写入的存储寄存器个数（范围 1~60）。
- **指令「字节数」= 数据个数 × 2**（手册注：指令信息内指定的字节数设定为指令信息中的数据个数 ×2）。
- 响应（正常）**不回显**字节数与各寄存器数据，仅回显数据个数。
- 异常响应功能码同读：`E7`。

### 2.2 示例（手册表 6.12）：向从站 1 写入频率指令与转矩限制指令

- `0002H`：频率指令 = 60.00 Hz（6000 = 1770H）
- `0004H`：转矩极限 = 150.0%（1500 = 05DCH）

**指令（18 字节）**：完整字节 `01 67 01 0E 00 02 00 04 00 02 17 70 00 04 05 DC 55 59`

| 字节 | 内容                        | 设定数据(Hex.) |
| ---- | --------------------------- | -------------- |
| 0    | 从站地址                    | 01             |
| 1    | 功能码                      | 67             |
| 2    | 辅助功能码（高位）          | 01             |
| 3    | 辅助功能码（低位）          | 0E             |
| 4    | 数据个数（高位）            | 00             |
| 5    | 数据个数（低位）            | 02             |
| 6    | 字节数（高位）              | 00             |
| 7    | 字节数（低位）              | 04             |
| 8    | 存储寄存器 1 的编号（高位） | 00             |
| 9    | 存储寄存器 1 的编号（低位） | 02             |
| 10   | 存储寄存器 1 的数据（高位） | 17             |
| 11   | 存储寄存器 1 的数据（低位） | 70             |
| 12   | 存储寄存器 2 的编号（高位） | 00             |
| 13   | 存储寄存器 2 的编号（低位） | 04             |
| 14   | 存储寄存器 2 的数据（高位） | 05             |
| 15   | 存储寄存器 2 的数据（低位） | DC             |
| 16   | CRC-16（高位）              | 55             |
| 17   | CRC-16（低位）              | 59             |

**响应（正常，8 字节）**：完整字节 `01 67 01 0E 00 02 D5 FC`

| 字节 | 内容               | 设定数据(Hex.) |
| ---- | ------------------ | -------------- |
| 0    | 从站地址           | 01             |
| 1    | 功能码             | 67             |
| 2    | 辅助功能码（高位） | 01             |
| 3    | 辅助功能码（低位） | 0E             |
| 4    | 数据个数（高位）   | 00             |
| 5    | 数据个数（低位）   | 02             |
| 6    | CRC-16（高位）     | D5             |
| 7    | CRC-16（低位）     | FC             |

**响应（故障，5 字节）**：同读：`01 E7 02 EA 31`

## 3. 确定指令（Enter；寄存器 0900 / 0910）

使用 MEMOBUS 通信从 PLC 向变频器写入参数时，确定指令是否使这些参数有效取决于参数 H5-11［通信的 ENTER 功能选择］的设定。

变频器支持 2 种确定指令（手册表 6.13）：**在寄存器编号 0900 或 0910 (Hex.) 中写入 0 即执行确定指令**。这些寄存器**仅可写入**，如果使用这些寄存器读入数据，则会发生故障（寄存器编号不当 02）。

| 寄存器编号(Hex.) | 内容                                                                                      |
| ---------------- | ----------------------------------------------------------------------------------------- |
| 0900             | 将参数数据写入 EEPROM 的同时 RAM 上的数据生效。即使关闭变频器电源，参数的变更也不会失效。 |
| 0910             | 参数数据不写入 EEPROM，仅更新 RAM 上的数据。如果关闭变频器的电源，参数的变更会失效。      |

**注**：

- 变频器所用 EEPROM 最多可写入 10 万次。请注意不要频繁执行向 EEPROM 写入确定指令（0900 (Hex.)）。
- 确定指令的寄存器为写入专用；读取这些寄存器时返回寄存器编号不当（02 (Hex.)）。
- 将指令数据或广播式发送数据发往变频器时，无需确定指令。

## 4. MEMOBUS 通信故障代码一览（手册表 6.20）

发生故障后，排除故障原因，再次开始通信。

| 故障代码(Hex.) | 名称                   | 原因                                                                                                                                                                                                                                                                                                                    |
| -------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 01             | 功能码错误             | 从 PLC 设定了 03、08、10 (Hex.) 以外的功能码。                                                                                                                                                                                                                                                                          |
| 02             | 寄存器编号不当故障     | 要访问的寄存器编号一个也未登记。执行广播式发送时，设定了 0001 或 0002 (Hex.) 以外的开始编号。                                                                                                                                                                                                                           |
| 03             | 个数不当错误           | 读取或写入的数据个数超过 1~~16 的范围（指令信息的数据个数无效）。读取非连续保持寄存器的内容时，数据个数超过了 1~~120 的范围。写入到非连续保持寄存器时，数据个数超出了 1~60 的范围。写入模式下，信息中的字节数不是数据数 ×2。                                                                                            |
| 21             | 数据设定错误           | 写入控制数据或参数时发生单纯的上下限错误。参数写入时发生参数设定不当。                                                                                                                                                                                                                                                  |
| 22             | 写入模式错误           | 试图在运行中写入不能写入的参数。发生 CPF06［控制回路不良（EEPROM 数据）］时，试图从主站写入下述以外的参数：A1-00［LCD 操作器显示语言的选择］、A1-01［参数访问级］、A1-02［控制模式的选择］、A1-03［初始化］、A1-04［密码］、A1-05［密码设定］、E1-03［V/f 曲线选择］、o2-04［变频器容量选择］。试图写入读取专用的数据。 |
| 23             | 主回路欠电压中写入错误 | 试图从主站将不可写入 Uv 中的参数写入 Uv［主回路欠电压］。                                                                                                                                                                                                                                                               |
| 24             | 参数处理时的写入错误   | 在变频器侧进行参数处理时，试图从主站写入参数。                                                                                                                                                                                                                                                                          |
| 25             | EEPROM 写入禁止        | 在 EEPROM 写入禁止的状态下，执行了来自通信的 EEPROM 写入指令。（发生该故障时，显示相应信息，但继续运行。）                                                                                                                                                                                                              |

## 5. 从站无响应条件

从站在以下情况下**忽视主站的指令信息，也不发送响应信息**：

- 在指令信息中检出传送故障（超调、成帧、校验、CRC-16）
- 指令信息内的从站地址和变频器侧的从站地址不一致（变频器的从站地址用 H5-01［从站地址］设定）
- 构成信息的数据之间的时间间隔超过 24 位长度时
- 指令信息的数据长度不正确时

**注**：

- 操作器上显示 CALL［SI-B 通信错误］时，请参照故障排除章节排除故障，重新进行通信。操作器上显示 CALL 时，通过 U1-19［MEMOBUS 通信故障代码］确认是否发生故障以及故障的类型。
- 执行写入功能时，在指令信息内指定的从站地址为 00 (Hex.) 时，尽管所有的从站执行写入，但不向主站发送响应信息（广播写）。

## 6. 测试向量汇总（实现/测试用）

来源：手册表 6.11 / 6.12。**已确认（用户 2026-08-31）：手册向量与标准 CRC-16/MODBUS（poly 0x8005，init 0xFFFF，反射，低字节在前）一致**，`plugins/yaskawa-memobus-67h-010dh-010eh` 插件按标准 CRC-16/MODBUS 实现即可。

| 用例                  | 帧字节                                                  |
| --------------------- | ------------------------------------------------------- |
| 读指令（表 6.11）     | `01 67 01 0D 00 02 00 24 00 28 8B 29`                   |
| 读响应（正常）        | `01 67 01 0D 00 04 17 70 03 E8 47 ED`                   |
| 异常响应（错误码 02） | `01 E7 02 EA 31`                                        |
| 写指令（表 6.12）     | `01 67 01 0E 00 02 00 04 00 02 17 70 00 04 05 DC 55 59` |
| 写响应（正常）        | `01 67 01 0E 00 02 D5 FC`                               |

数量上限：**读 ≤ 120**、**写 ≤ 60**（表 6.20 错误码 03 说明）。
