# 侧边栏展开态横向滚动条定位错误

> 日期：2026-09-08　状态：已验证
> 关联：ADR-041 侧边栏分组 / 侧边栏可用性项

## 现象

侧边栏展开态下，当协议分组标题文本较长（如 `Read/write via 03H/10H`）时，产生一条水平滚动条，且它出现在**最后一个菜单项文本下方**，而不是贴合侧边栏容器底部。

复现步骤：`pnpm dev` → 打开 `http://localhost:5173/?mockTransport=1`，默认工作区协议组「Read/write via 03H/10H」标题即较长，直接可见。

## 根因分析

（根因而非症状）

1. **高度计算错误（滚动条位置）**：`.sheet-sidebar__groups` 是 `.sheet-sidebar`（flex 列）的子项，但**未设 `flex:1`**，其高度等于内容高度而非填满。`overflow:auto` 的水平滚动条因此渲染在 `groups` 底边（紧随最后一项），而非侧边栏底部。实测 `groups` `height=274px`（仅内容高），footer 在其下方约 305px 处。
2. **溢出来源（文本过长）**：`.sheet-sidebar__group-title` 虽带 `overflow:hidden; text-overflow:ellipsis; white-space:nowrap`，但**缺少 `flex:1; min-width:0`**。作为 `.sheet-sidebar__group-head`（flex）的子项，其 `min-width:auto` + `nowrap` 使最小内容宽 = 整段标题文本宽，无法收缩，把「+」按钮连同标题整体推出容器 → 横向溢出（`group-head` width=179、right=215 > 容器右缘 159）。
3. **根 UL 溢出（叠加）**：antd `.ant-menu-inline { width:100% }` 叠加 `.sheet-sidebar__list` 的 `margin: 2px 4px`，使根菜单 UL 超出容器 4px，贡献水平滚动条余量。
4. **antd 特异性覆盖**：`.ant-menu-inline.ant-menu-root .ant-menu-submenu-title > * { flex: none }`（0,3,0）给分组头设 `flex:none`（不收缩），需更高特异性/`!important` 覆盖。

## 复现测试（强制）

- 测试文件：`tests/e2e-web/tests/sidebar-scrollbar.spec.ts`
- 预期失败（红）：`.sheet-sidebar__groups` `scrollWidth=167 > clientWidth=159` → 断言 `scrollWidth <= clientWidth` 失败。
- 修复后通过（绿）：长分组标题收缩省略号 + 容器填满高度，无水平溢出。

## 修复方案

- 方案：
  - `.sheet-sidebar__groups` 补 `flex:1;` —— 分组容器填满剩余高度，任何水平滚动条贴合侧边栏底部。
  - `.sheet-sidebar__group-title` 补 `flex:1; min-width:0;` —— 长标题收缩并省略号显示，消除横向溢出。
  - `.sheet-sidebar__menu.sheet-sidebar__sidebar-menu .sheet-sidebar__group-head` 补 `flex:1 1 auto !important; min-width:0;` —— 覆盖 antd `submenu-title > * { flex:none }`，使分组头可收缩。
  - `.sheet-sidebar__menu.ant-menu-root.ant-menu-inline` 补 `width:auto;` —— 覆盖 antd `width:100%`，避免根菜单因 4px margin 溢出。
- 影响文件：`apps/web/src/index.css`
- 兼容处理：纯布局/CSS 微调，不涉及 JS、数据、协议、持久化、能力矩阵、HostMessage；折叠态不受影响。

## 后续设计优化（方案 A，2026-09-08）

上述布局修复使分组头可收缩后，暴露了「antd 折叠箭头 `^` 与「+」新建按钮重叠」的问题（`.ant-menu-submenu-arrow` 与 `.sheet-sidebar__group-action` 撞位）。经用户选择**方案 A**：

- **隐藏** antd `.ant-menu-submenu-arrow`（CSS `display:none`），不再显示独立折叠符号。
- **点击分组名即可折叠/展开**（antd Menu 默认行为），标题区悬停高亮。
- 分组名加 **Tooltip 提示**「Click to expand/collapse / 点击展开/折叠」（i18n 键 `sidebar.toggleGroup`，en/zh-CN）。
- 「+」为唯一右侧操作按钮，`stopPropagation` 使其不触发折叠（含自身 `sidebar.newTable` Tooltip）。
- 折叠窄条（36px）隐藏标题/加号，仅保留分组图标入口。
- 涉及文件：`packages/ui/src/MamepApp.tsx`（分组名包 Tooltip）、`packages/ui/src/i18n/index.ts`（`sidebar.toggleGroup`）、`apps/web/src/index.css`（隐藏箭头、折叠态隐藏）。
- 验证：侧边栏 e2e 22/22、`packages/ui` 单测、typecheck 30/30、lint 全绿。
