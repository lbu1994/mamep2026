# 页签重命名输入框焦点未落位

> 日期：2026-09-06　状态：已验证
> 关联：ADR-018（页签重命名）；`sheet-rename-edit-state-isolation-2026-08-21.md` 记忆

## 现象

双击页签标签（或右键菜单 Rename）进入更名后，重命名输入框出现，但**焦点未落在输入框内**，仍停留在 `.ant-tabs-tab-btn`（页签按钮），须手动点击才能输入；并连带引发一系列异常：

- 键盘输入无效（按键走页签键盘导航，`Backspace`/`Delete` 可能触发 rc-tabs `handleRemoveTab` → 关闭页签/移焦点）；
- 编辑态挂载即触发 blur、异常退出，名称可能被误提交；
- 视觉上输入框以非聚焦控件呈现（「一系列显示 bug」）。

## 根因分析

**表层**：`packages/ui/src/MamepApp.tsx` 页签头的 `SheetNameEditor` 未传 `autoFocus`（约第 989 行），输入框挂载后不聚焦。

**深层（导致不能简单加 `autoFocus` 的真正原因）**：重命名输入框是 `.ant-tabs-tab-btn`（rc-tabs 可聚焦页签按钮）的**后代**（`label` 渲染在 tab button 内部）。当输入框获得焦点时，`focus` 事件**冒泡**到 `.ant-tabs-tab-btn` 的 React `onFocus` 处理器；rc-tabs `TabNavList`（`node_modules/@rc-component/tabs/.../TabNavList/index.js`）在 `!isMouse` 时会 `setFocusKey(key)`，使对应 `TabNode` 的 `focus` 属性为 `true`；而 `TabNode`（`TabNode.js`）有：

```js
React.useEffect(() => {
  if (focus && btnRef.current) btnRef.current.focus();
}, [focus]);
```

随即调用 `btnRef.current.focus()` **把焦点抢回 tab button** → 输入框立即 `blur` → `onBlur` → `onCommit` → 编辑态异常退出（输入框被移除）。这正是历史记录「dblclick 第二次 click 抢焦点触发 blur 退出」的根源——实为 focus 冒泡 + rc-tabs focus 回流链路。

## 复现测试（强制）

- 测试文件：`packages/ui/src/MamepApp.test.tsx`
- 用例：`页签头双击进入编辑态后，焦点落在重命名输入框内`
- 使用 `userEvent.dblClick`（触发完整鼠标序列，mousedown 聚焦 `.ant-tabs-tab-btn`）复现。
- **红**（修复前）：`document.activeElement` 为 `.ant-tabs-tab-btn` 的 `<div>`，断言 `expect(document.activeElement).toBe(input)` 失败。
- **绿**（修复后）：`document.activeElement` 为输入框 `<input class="sheet-tab__input">`。

## 修复方案

- 方案：
  1. `SheetNameEditor` 输入框增加 `onFocus={(event) => event.stopPropagation()}`，阻断 `focus` 冒泡到 `.ant-tabs-tab-btn` 的 `onFocus`，切断 rc-tabs 的 focus 抢回链路。
  2. 页签头 `SheetNameEditor` 增加 `autoFocus`，输入框挂载即聚焦（与侧边栏一致）。
- 影响文件：
  - `packages/ui/src/components/SheetNameEditor.tsx`
  - `packages/ui/src/MamepApp.tsx`
  - `packages/ui/src/MamepApp.test.tsx`（复现测试）
- 兼容处理：`onFocus` 阻止冒泡对侧边栏 Menu 项无影响（无 focus 处理器）；输入框既有 `onClick`/`onKeyDown` 已 stopPropagation，行为不变。

## 影响范围与回归

- 受影响模块：`packages/ui`（SheetNameEditor / MamepApp 页签头）。
- 回归测试：`MamepApp.test.tsx` 全部用例（Enter 提交 / 失焦提交 / Escape 取消 / Backspace 不关闭标签 / 互斥等）应保持绿；e2e `sidebar-menu.spec.ts` 侧边栏重命名走右键菜单路径，输入框行为不变。
- 执行时机：**由用户决定**（docs/AGENTS.md §27）。
