# 侧边栏 footer 未区分三端平台标识

> 日期：2026-09-03　状态：已验证
> 关联 ADR：无（UI 文案/宿主接口小改动，不涉及架构决策）

## 现象

侧边栏底部版本 footer 在浏览器 / Electron / VSCode 三端运行时均显示 `Browser v<版本>`，
未按运行平台区分；且无中文文案。用户期望：

| 平台        | 英文                | 中文             |
| ----------- | ------------------- | ---------------- |
| 浏览器      | `Browser v<版本>`   | `浏览器 v<版本>` |
| Electron    | `Client v<版本>`    | `客户端 v<版本>` |
| VSCode 插件 | `Extension v<版本>` | `插件 v<版本>`   |

## 根因分析

- UI 层侧边栏 footer（`packages/ui/src/MamepApp.tsx` ~L844-846）固定使用单一 i18n 键
  `sidebar.footer`，en/zh 两套文案均硬编码为 `"Browser v{{version}}"`，与平台无关。
- 更深一层：UI 层拿到的是 `AppHost` 接口（`packages/ui/src/host.ts`），该接口没有暴露
  平台类型字段。平台判别信息只存在于 `apps/web/src/App.tsx` 装配时的 `window.mamepHost`
  （`bridge.platform` 为 `"electron"` / `"vscode"`，浏览器端无 bridge 为 `undefined`），
  装配时被用于选择宿主类后就丢弃，未传递到 UI 层。因此组件「不知道该显示哪个平台名」。

## 复现测试（强制）

- 测试文件：`packages/ui/src/MamepApp.test.tsx`（新增 `侧边栏 footer 按平台显示（bug 修复）` describe）
  - 前置：`AppHost` 接口新增 `platform` 字段 + `make-app-host.ts` 测试桩支持 `platform` 覆盖。
- 红：修复前，Electron/VSCode 用例断言失败——footer 仍为 `Browser v0.0.0-test`，而非
  `Client v0.0.0-test` / `Extension v0.0.0-test`（2 failed）。
- 绿：修复后，15/15 通过。

## 修复方案

- 方案：`AppHost` 接口新增 `readonly platform: "browser" | "electron" | "vscode"`；
  三端宿主类实现该字段（Browser=`"browser"`、Electron=VSCode 宿主从装配平台固定）；i18n
  将 `sidebar.footer` 拆为 `sidebar.footerBrowser` / `footerClient` / `footerExtension`
  三键（en/zh）；`MamepApp` footer 按 `host.platform` 选择对应键。
- 影响文件：
  - `packages/ui/src/host.ts`：`AppHost` 新增 `platform` 字段。
  - `packages/ui/src/i18n/index.ts`：en/zh 拆三键。
  - `packages/ui/src/MamepApp.tsx`：footer 按平台选键。
  - `packages/ui/src/test/make-app-host.ts`、`packages/ui/src/components/ConnectionSettingsModal.tcp.test.tsx`：测试桩补 `platform`。
  - `apps/web/src/AppHost.ts`：`BrowserAppHost.platform = "browser"`；私有 `platform` 字段重命名
    为 `platformHost`（避免与公开 `platform` 冲突）。
  - `apps/web/src/electron-app-host.ts`：`ElectronAppHost.platform = "electron"`；同理重命名私有字段。
  - `apps/web/src/vscode-app-host.ts`：`VscodeAppHost.platform = "vscode"`。
- 兼容处理：值语义变更（为 `platform` 加常量只读字段），公共协议/HostMessage v1/能力矩阵/
  持久化 schema 零改动；浏览器端 footer 文案与版本号保持不变（既有 e2e

`tests/e2e-web/tests/sidebar-menu.spec.ts` 断言 `/Browser v\d+\.\d+\.\d+/` 仍成立）。

## 影响范围与回归

- 受影响模块：`packages/ui`、`apps/web`。
- 回归测试：`packages/ui` 315 用例、`apps/web` 79 用例全绿；`web`/`ui` 包 `tsc --noEmit` 通过；
  ESLint 改动文件通过。涉及界面，可提醒浏览器 e2e `sidebar-menu.spec.ts` 冒烟。
- 执行时机：**由用户决定**（docs/AGENTS.md §27）。
