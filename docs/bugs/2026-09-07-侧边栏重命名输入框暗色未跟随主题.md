# 侧边栏 Rename 输入框暗色下未跟随主题（白底黑字）

> 日期：2026-09-07　状态：已验证
> 关联 ADR：docs/adr/ADR-027-VSCode主题完整适配.md（主题令牌映射）；与其后的 ADR-048 默认主题色跟随 antd 同域。

## 现象

暗黑模式下，在侧边栏对 sheet 项右键菜单选择 **Rename** 后，内联编辑输入框显示为「白底黑字」（明亮模式样式），未跟随暗色主题；页签头的重命名输入框则正常跟随暗色。

复现步骤：

1. 启动应用（`?mockTransport=1`），连接就绪；
2. Settings → 主题切到 **Dark**；
3. 侧边栏右键某个 sheet 项 → **Rename**；
4. 观察 `.sheet-item__input`：背景为白、文字为黑（浏览器 UA 默认）。

## 根因分析

`apps/web/src/index.css` 中两侧重命名输入框样式定义不一致：

- `.sheet-tab__input`（页签头重命名，约 599 行）**显式设置**了 `background: var(--ant-color-bg-container)` 与 `color: var(--ant-color-text)`，因此跟随暗色主题；
- `.sheet-item__input`（侧边栏重命名，约 357 行）**只设置**了 `border`，**未设置** `background` 与 `color`。

HTML `<input>` 元素使用浏览器 UA 默认样式（白底黑字），且**不继承**父元素的 `color` / `background`。侧边栏 `.sheet-item` 虽设了 `color: var(--ant-color-text)`，但不会传递到输入框内部的 UA 背景/文字色。应用根未设置 `color-scheme: dark`（`apps/web/src/index.css` 无该声明），故暗色下输入框仍以 UA 默认「白底黑字」渲染。

## 复现测试（强制）

- 测试文件：`tests/e2e-web/tests/sidebar-rename-dark-theme.spec.ts`
- 断言：暗色下 `.sheet-item__input` 的 computed `background-color` 不为 `rgb(255,255,255)`、`color` 不为 `rgb(0,0,0)`。
- **红**（修复前）：`expect(bg).not.toBe("rgb(255, 255, 255)")` 失败，实测 computed 背景为 `rgb(255, 255, 255)`。
- **绿**（修复后）：`1 passed`。

## 修复方案

- 方案：对齐 `.sheet-tab__input`，为 `.sheet-item__input` 补齐 `background: var(--ant-color-bg-container)`、`color: var(--ant-color-text)`、`outline: none`。
- 影响文件：`apps/web/src/index.css`（仅一处样式，组件/逻辑零改动）。
- 兼容处理：`--ant-color-bg-container` / `--ant-color-text` 为 antd 运行时令牌，浅色下取值即浅色值，不影响浅色主题；浏览器 / Electron / VSCode 三端共享该 CSS，一并修复。

## 影响范围与回归

- 受影响模块：`apps/web`（共享 UI 样式，三端）。
- 回归测试：`pnpm --filter @mamep2026/e2e-web test -- sidebar-rename-dark-theme.spec.ts`（复现用例已绿）。受影响包单测（`packages/ui`）与 `pnpm typecheck` / `pnpm lint`。
- 执行时机：**由用户决定**（docs/AGENTS.md §27）。
