# 侧边栏展开态可调节宽度（antd `Splitter`）

> 日期：2026-09-08　状态：完成
> 关联决策：ADR-041 侧边栏分组 / 侧边栏折叠态项（单个 Menu + SubMenu + `inlineCollapsed`/`SiderContext` 弹出行为）
> 验证：`pnpm test:all` 全绿（真实端口 e2e web 14/electron 27/vscode、ui 343、acceptance 5、mock e2e web 135/electron 30/vscode、串口虚拟 109、lint、typecheck 30/30）。

## 需求摘要

侧边栏**展开态**下通过 antd `Splitter` 拖拽分隔条调节侧边栏与内容区宽度；**折叠态**（仅图标、36px）固定不可拖宽，二者互斥。

## 边界条件

- 仅展开态可拖宽；折叠态固定 36px、`resizable={false}`，分隔条不可拖。
- 宽度约束：`min=120`、`max="40%"`、默认 `160px`。
- 拖拽过程本地缓冲（`onResize` 更新本地、`onResizeEnd` 才写 store），避免高频写 `panelLayout`。
- 宽度随工作区持久化（新增 `panelLayout.sidebarWidth`），重启/切换工作区后恢复。
- 折叠 → 展开切换时回到上次展开宽度（`sidebarWidth`）。

## 异常场景

- 容错：老工作区缺 `sidebarWidth` 由 zod `.default()` 补齐 160，无迁移、不 bump schemaVersion。
- 折叠 ↔ 展开：分隔条随 `resizable` 自动显示/隐藏，无残留状态。
- 水平/竖向 Splitter 嵌套：内容区高度经 `height:100%` 约束（Splitter 面板非 flex 容器）。

## 性能与安全

- 性能：拖拽期间仅本地 state，`onResizeEnd` 才持久化，无高频写 store。
- 安全/权限：纯 UI 布局改动；不涉及协议层/调度器/能力矩阵/HostMessage；三端复用共享 UI 自动生效。

## 计划（Plan 摘要）

1. domain：`PanelLayout.sidebarWidth` + 默认 160 + 导出 `DEFAULT_SIDEBAR_WIDTH`。
2. workspace：schema `panelLayout.sidebarWidth` 设 default（不 bump schemaVersion）。
3. ui：`MamepApp` 主布局替换为水平 `Splitter`（保留 `ant-layout-sider`/`ant-layout-sider-collapsed` 类名），`Menu` 折叠态改显式 `inlineCollapsed`，`onResize`/`onResizeEnd` 持久化 `sidebarWidth`。
4. css：`.mamep-main`/`.mamep-body` 适配、`.sheet-sidebar.ant-layout-sider` 覆盖 antd Sider 背景/过渡、`.sidebar-panel__resize` 样式、清理 `.ant-layout-sider-children`。
5. 测试：新增 e2e `sidebar-resize.spec.ts` + 轻量单测（workspace schema round-trip / domain 默认值）。

## 测试策略

- 新增/修改测试：
  - `tests/e2e-web/tests/sidebar-resize.spec.ts`：拖 `sidebar-panel__resize` 改宽并断言内容区变宽 / reload 持久化 / 折叠态不可拖 / 无 console 错误。
  - `packages/workspace/src/schema.test.ts`：round-trip 含 `sidebarWidth` 默认 160。
  - `packages/domain`：`createDefaultWorkspace` 默认值断言（轻量）。
- 回归重点：既有 e2e（`sidebar-menu`/`sidebar-collapsed`/`redesign` 等 9 个 spec）对 `.ant-layout-sider` / `.ant-layout-sider-collapsed` / `.ant-menu-inline-collapsed` 选择器依赖，保留类名应全部不变；`MamepApp.test.tsx` 用 `.sheet-sidebar__*` 选择器不受影响。
- 执行时机：**由用户决定**（docs/AGENTS.md §27）；不得谎报。

## 风险与回滚

- 风险：①`Splitter.Panel` 手动挂 `ant-layout-sider` 引入 antd Sider 注入的 `background/transition/position`，已用 `.sheet-sidebar.ant-layout-sider` 覆盖，需浏览器冒烟确认；②水平/竖向 Splitter 嵌套后 `.mamep-body` 高度约束与底部面板拖拽是否回归，需冒烟；③`Menu inlineCollapsed` 折叠弹出行为与 ADR-041 一致性，用既有 `sidebar-collapsed.spec.ts` 复验。
- 回滚：改动集中在 `MamepApp.tsx` 布局区 + CSS + domain/schema 增量字段；还原 `MamepApp.tsx`/`index.css` 为 `Layout.Sider` 版本、删除 `sidebarWidth` 字段即回退（字段为 `.default()` 增量、无迁移依赖，回滚安全）。
