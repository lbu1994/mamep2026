# 侧边栏折叠态分组子菜单弹出

> 日期：2026-09-08　状态：进行中
> 关联决策：docs/adr/ADR-041-插件PhaseC安川插件与表类型.md（侧边栏按协议分组）

## 需求摘要

侧边栏折叠到 36px 窄条时，分组及其子菜单（各协议组的表项）当前完全隐藏、不可用；本功能让折叠态下每个分组以图标入口呈现，悬停即弹出该组表项子菜单，可直接点击切换/打开表。

## 边界条件

- 仅针对侧边栏折叠态；展开态的分组折叠记忆、组内拖拽排序、每表 More/右键菜单、重命名等交互保持不变。
- 折叠窄条宽度固定 `collapsedWidth={36}`，分组图标入口需在窄条内可容纳（CSS 精调 antd 折叠 Menu 项宽/内边距）。
- 空分组（该组无任何表）在折叠态弹层内表现为空子菜单，不提供新建入口。
- **折叠态不提供新建表入口**（用户决策 2026-09-08）：窄条顶部独立「＋」按钮因无法标明新建的表类型、易混淆，已移除；折叠态仅用于切换表，新建表需展开侧边栏后经分组头「＋」。

## 异常场景

- 折叠弹层悬停打开期间：点击表项切换活动表；重新展开侧边栏 / 关闭侧边栏 / 切换表均安全（弹层随 Menu 状态关闭）。
- 跨组拖拽：单 Menu 合并后需显式守卫，禁止把 A 组表项拖入 B 组（不同表类型），维系 ADR-041 决策⑥。

## 性能与安全

- 性能：纯 UI 层重构，无协议/持久化/能力矩阵改动；无新增请求。
- 安全：不涉及串口/TCP/文件系统；不新增内置插件；不扩展产品范围。

## 计划（Plan 摘要）

1. `MamepApp.tsx`：移除 `Collapse`，改为单 `<Menu mode="inline">`，`items` 由 `sheetGroups.map(group => ({ key, icon, label, children }))`，每个分组一个 `SubMenu`。
2. 折叠态自动弹层：去掉显式 `inlineCollapsed={false}`，借助 `SiderContext`（`sidebarCollapsed` → `inlineCollapsed`）。
3. 分展开/折叠用受控 `openKeys` 映射现有 `collapsedGroups`。
4. 组头 label = [组图标 + 组标题 + 「＋」新建]，「＋」stopPropagation。
5. 表项 label 按 `sidebarCollapsed` 渲染：折叠态简化（仅切换），展开态保留完整（右键/More/重命名/拖拽）。
6. 根 Menu 拖拽处理增加 `data-sheet-group` 同组守卫（跨组 return），维系 ADR-041 决策⑥。
7. 按 `sheetType` 提供组图标，保证窄条可区分。

## 风险与回滚

- 风险：①36px 窄条内 antd 折叠 Menu 默认项宽需 CSS 精调；②单 Menu 合并后跨组拖拽需显式守卫；③`openKeys` 受控与既有分组折叠记忆语义扰动。
- 回滚：改动集中在 `MamepApp.tsx` 侧边栏 JSX 与 `apps/web/src/index.css` 折叠段；如回归不可控，回退为「保留 Collapse + 折叠态自定义 Popover 弹层」。
