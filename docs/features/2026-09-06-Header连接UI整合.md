# Header 连接 UI 整合（单一多功能按钮）

> 日期：2026-09-06　状态：完成
> 关联决策：ADR-022（连接状态）/ ADR-035（状态点与自动重连）/ 2026-09-06 Header Connect 直连（`connection-actions.ts`）

## 需求摘要

将 Header 左侧「连接状态显示」（只读状态胶囊：状态点 + 状态文字）与「Connect/Disconnect 按钮」合并为一个**多功能按钮**（一体化控件：状态点并入按钮 + 按钮文字随连接状态切换）。

## 边界条件

- 仅合并 Header 连接区（`.connection-cluster`）内的状态胶囊 + Connect/Disconnect 按钮；右侧「Connection / Plugin Manager / Settings / Help」按钮组、侧边栏、BottomPanel（Comm Properties 状态读数）不在本次范围。
- PRD §6.1.2 / §6.2.2 约束不可突破：按钮上必须保留「状态文字 + 语义色」，不能只靠颜色。
- PRD §6.2.4：`failed` / `interrupted` 状态下点击按钮 = 重连入口。
- PRD §10.6：窄窗口（`max-width:1100px`）允许收起文字，但仍保留状态点（不隐藏连接状态）。

### 按钮 label 矩阵（`connectionButtonSpec`）

| 状态                | 可见文字              | 状态点 | 呼吸 | type                    | 操作图标           | 点击行为                   |
| ------------------- | --------------------- | ------ | ---- | ----------------------- | ------------------ | -------------------------- |
| `disconnected`      | `Connect`             | 灰     | 否   | default（主题主色描边） | Api                | 直连或回退弹窗             |
| `selecting-device`  | `Selecting device`    | 主色   | 是   | default                 | Api                | 允许点击（忙态守卫 no-op） |
| `connecting`        | `Connecting`          | 主色   | 是   | default                 | Api                | 允许点击（忙态守卫 no-op） |
| `connected`         | `Online / Disconnect` | 绿     | 否   | default                 | DisconnectOutlined | 断开                       |
| `disconnecting`     | `Disconnecting`       | 主色   | 是   | default                 | Disconnect         | 允许点击（忙态守卫 no-op） |
| `reconnect-waiting` | `Reconnect pending`   | 警告   | 否   | default                 | Api                | 允许点击（忙态守卫 no-op） |
| `reconnecting`      | `Reconnecting`        | 主色   | 是   | default                 | Api                | 允许点击（忙态守卫 no-op） |
| `interrupted`       | `Interrupted`         | 警告   | 否   | default                 | Api                | 重连入口                   |
| `failed`            | `Connection failed`   | 错误   | 否   | default                 | Api                | 重连入口                   |

## 异常场景

- `failed` / `interrupted` 点击：落到连接路径（`runConnect` → `host.connect`/`connectTcp`）；`SessionHostCore.connect` 会先断开旧会话再新建连接，故重连可行。
- 过渡态（connecting/disconnecting/reconnecting/reconnect-waiting/selecting-device）点击：按钮可点，但 `handleConnectToggle` 忙态守卫忽略（no-op），避免并发连接。
- `disconnected` 点击：沿用「直连 or 回退弹窗」逻辑（`canDirectConnect` / `runConnect`，2026-09-06 已落地）。

## 性能与安全

- 纯 UI / 样式改动；零协议层 / 调度器 / HostMessage / 能力矩阵 / 持久化变更。
- 状态点颜色沿用 `STATE_DOT_COLOR`（antd 语义 token），不新增硬编码色值。
- 过渡态呼吸动画尊重 `prefers-reduced-motion`（维持现状）。
- 保留 `aria-label` / `title` 反映点击语义，避免「状态文字 = 操作文字」a11y 混淆。

## 计划（Plan 摘要）

1. `connection-button.ts`：导出 `ConnectionButtonSpec` 与 `connectionButtonSpec(state, narrow)`。
2. `MamepApp.tsx`：用单一 `Button` 承载「状态点 + 文字 + 操作图标」，`data-conn-state={connectionState}`；窄窗口隐藏文字只留状态点 + 图标。
3. `handleConnectToggle`：忙态守卫补 `selecting-device`；`failed`/`interrupted` 不守（落到连接路径）即重连入口。
4. i18n：新增 `topbar.connected` / `topbar.reconnect`。
5. CSS：新增 `.connection-cluster__button` / `.conn-btn__dot`，迁移状态色与呼吸动画；去掉 `.connection-cluster__sep`。
6. 适配 `redesign-states.spec.ts`。

## 风险与回滚

- 风险：`connected` 显示 "Online / Disconnect" 文字稍长（窄窗口收起缓解）；`redesign-states.spec.ts` 的 `.status-badge` 断言需同步更新；`interrupted` 点击重连依赖 `host.connect` 替换会话（已确认行为正确）。
- 回滚：纯 UI/样式改动，无协议/持久化变更；还原 `MamepApp.tsx` + `index.css` + 删除新增文件即可整体回退。
