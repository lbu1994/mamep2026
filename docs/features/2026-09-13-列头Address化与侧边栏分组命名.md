# 列头 Address 化与侧边栏分组命名（列/表语义泛化）

> 日期：2026-09-13　状态：完成
> 关联决策：修订 [docs/adr/ADR-014-寄存器地址进制显示选择.md](../adr/ADR-014-寄存器地址进制显示选择.md)（列头文案）；关联 ADR-041（侧边栏分组）/ ADR-043（基础表类型）/ ADR-015（剪贴板 CSV）

## 需求摘要

寄存器表的「Register」列头与侧边栏协议分组文案在**非保持寄存器表类型**（线圈 / 离散输入 / 输入寄存器）下不再准确：列头叫「Register」、分组只写「用 03H/10H 读写寄存器」（未表达读/写属性与功能码含义）。本次把列/表语义泛化并明确读写属性：

1. **列头**：`Register[DEC]` / `Register[HEX]` → `Address[DEC]` / `Address[HEX]`（中文「寄存器[DEC]」→「地址[DEC]」）；连带工具栏标签 `Address:`、aria-label `Address format`、提示文案，以及地址单元格 `aria-label="Register"` → `"Address"`。
2. **侧边栏分组**：改为明确读/写属性（不再显示功能码）。
3. **表级命名去 Register**：侧边栏分区 `Register Tables` → `Tables`（中文「寄存器表」→「表格」）、新建入口 `New Register Table` → `New Table`（「新建寄存器表」→「新建表格」）、帮助页签 / 快捷键分组与「新建表」描述同步。

## 关键决策（用户确认）

1. **保留进制后缀**（`Address[DEC]` / `Address[HEX]`），沿用 ADR-014 的「列头随模式动态」语义。
2. **连带工具栏一致化**（`Address:` / `Address format` / 提示文案），避免列头「Address」与工具栏「Register」自相矛盾。
3. **地址单元格 `aria-label` 同步改 `Address`**（保持**字面量、不进 i18n**：三端 e2e/单测以英文名定位，本地化会随语言切换而脆弱；`Name`/`Data`/`Comment` 同为字面量的 i18n 缺口另立待办）。
4. **系统剪贴板 CSV 表头** `Name,Register,...` → `Name,Address,...`。解码只按「首列是否为 `name`」跳表头，应用内 round-trip 与外部 CSV 兼容性均不受影响。
5. **分组英文去掉功能码**（按待办给定文案），中文「多个保持寄存器（读/写）」保留「多个」。
6. **i18n 键整理**：核心分组标题统一由 `table.tableType.*` 提供（`MamepApp` 核心组不再硬编码 `sidebar.groupModbus`）；删除死键 `sidebar.groupModbus` / `sidebar.groupMemobus` / `table.register` / `table.registerRadixHint` / `topbar.newSheet` / `topbar.newTable`。
7. **安川 67H 插件分组不动**（`plugins.yaskawaTableTypeTitle`，属插件自有命名）。

## 异常场景

- 插件 `tableType` 贡献的 titleKey 不受影响（插件自带标题优先）。
- `Address` 作为 `aria-label` 前缀会与工具栏「Address Adjust」「Address format」撞车 → e2e 一律 `exact: true`（或限定表格/行作用域），已在实施中统一收紧。

## 性能与安全

- 纯文案/键名/选择器改动，无性能与权限影响。

## 测试策略

- 单测：`packages/ui`（RegisterTable / HelpDrawer）、`packages/register-table`（row-clipboard）。
- 静态检查：`pnpm typecheck`、`pnpm lint`（已执行）。
- e2e：涉及三端全部地址列选择器，建议至少跑 `pnpm test:e2e:web` + `pnpm test:e2e:electron` 定向 spec。
- 执行时机：**由用户决定**（docs/AGENTS.md §27）；不得谎报。

## 风险与回滚

- 风险：`getByLabel("Address")` 非 exact 会命中「Address Adjust / Address format」；`New Table` / `Tables` 文案更短可能与其它控件同名。对策：`exact: true` + 作用域限定，必要时改用 `data-sheet-group` 定位。
- 回滚：全部为文案/键名/选择器改动，无 schema / 迁移 / 协议契约变更，直接 revert 即可，新旧工作区数据均兼容。
