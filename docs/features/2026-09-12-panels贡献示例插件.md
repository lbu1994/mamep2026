# `panels` 贡献示例插件（example-panel）

> 日期：2026-09-12　状态：完成
> 关联决策：ADR-039（插件功能设计与贡献点）/ ADR-047（主题色预设 + 方案 A 自带翻译）/ ADR-054（删除随包插件机制，§7.5 遗留「panels 无示例插件」）/ **不新增 ADR**（属既有贡献点收尾）

## 需求摘要

`plugins/example-theme` 已演示 `theme` 贡献点，但 `panels` 贡献点自 ADR-054 删除 `example-panel` 后**无任何随包/示例插件可供演示**。本次补一个纯清单示例插件 `plugins/example-panel`，演示「声明式面板贡献」的完整链路；同时给 `panels` payload 补**可选 `title`（插件自带翻译）**，与 `theme` 的方案 A 保持一致，使第三方插件不必依赖应用内置 i18n 键即可显示正确的面板标题。

## 边界条件

- **插件形态**：纯清单（`manifest.json`，无 `runtime`、无 `entry`、**无需同进程授权**）；权限 `["ui-contribution"]`、`platform.web = true`（安装强制要求）。
- **无贡献时**：底部面板不渲染「Plugins」页签（既有行为，`BottomPanel` 在 `pluginPanels.length === 0` 时不加该页签）；插件禁用/卸载后贡献回收、页签消失。
- **标题解析顺序**（方案 A，与 theme 一致）：`title[当前语言]` → `title["en-US"]` → 应用 i18n `titleKey` → `titleKey` 原文。
- **多面板**：一个插件可贡献多条面板，DOM key 为 `${pluginId}-${panelId}`（既有实现）。
- **面板内容**：仍为占位（`Divider` + `Empty`「插件面板内容将由插件运行时提供」）——交互式面板组件机制属 Phase F，本次**不做**。

## 异常场景

- `panels` payload 非法（缺 `id`/`titleKey`、`title` 缺 `en-US` 或为空串）→ 贡献点 schema 校验失败，插件**不注册**（既有 `PLUGIN_REGISTER_FAILED` 路径）。
- `title` 缺失 → 回退 `t(titleKey)`；`titleKey` 在应用 i18n 中不存在时 i18next 原样返回 key（不报错、不崩溃）。
- `host` 为空（无插件注册表）→ `PluginPanels` 返回 `null`（既有行为）。
- 旧插件 payload 不含 `title` → 可选字段，向后兼容，行为不变。

## 性能与安全

- 性能：无新增运行时开销（纯字符串解析 + 既有 `useSyncExternalStore` 订阅）；无新 chunk。
- 安全：不引入任何代码执行路径（纯清单插件）；不新增 HostMessage v1 kind；插件安装仍走既有 §6.10.4 安全确认。

## 计划（Plan 摘要）

1. 契约：`LOCALIZED_TITLE_SCHEMA` 抽出；`PANELS_CONTRIBUTION_SCHEMA` 元素增 `title?`。
2. 消费方：新增 `pluginLocalizedTitle()`；`themeColorTitle` 委托之；`PluginPanels` 用 `i18n.language` + 解析器渲染。
3. 示例插件：`plugins/example-panel`（纯清单 + TS 包壳 + 单测 + README）。
4. 构建：`pnpm build:plugins` 产出 `release/plugins/example-panel/manifest.json`。
5. e2e：新增 `plugin-panel.spec.ts`（复用 `helpers/manual-plugins.ts`）。
6. 文档：入门指南第 6 章 `panels` 行 + 纯清单面板插件示例；插件功能设计贡献点表同步。

## 风险与回滚

- 风险：
  - plugin-api 公共契约扩展（仅新增**可选**字段，旧插件不受影响）；
  - `themeColorTitle` 改为委托实现 → 由既有主题色解析用例守护，行为逐字等价；
  - e2e 依赖 `release/plugins`（gitignore）→ `test:e2e:web` 已自动先跑 `build:plugins`。
- 回滚：改动集中于 `plugin-api` 1 个文件、`ui` 3 个文件、1 个新插件包、1 行构建清单与文档；删除新包并回退 `title` 字段即恢复现状。**无数据迁移**（无 schemaVersion / HostMessage 变更）。
