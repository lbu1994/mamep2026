# 完整用户帮助

> 日期：2026-09-05　状态：完成
> 关联决策：复用 `documentation`/寄存器手册贡献点（ADR-043 E-5）；纯 UI + 文档内容，无新增 ADR。

## 需求摘要

将帮助从「弹出受限内容的小 Modal」改为「右侧 Drawer + 顶部 Tabs」承载完整用户帮助正文（PRD §8.3 P1），并按 `en-US`/`zh-CN` 双语填充内容；复用 ADR-043 E-5 的 markdown 渲染与已有组件。

## 边界条件

- 无插件文档：无 `documentation` 贡献时，不渲染「插件文档」页签。
- 语言：正文按当前语言解析（`zh* → zh-CN`，其余 `en-US`）；页签标题走 i18n。
- 打开时机：`Ctrl+/` / `?` 以及顶部「帮助」按钮均可打开；`helpModalOpen`（快捷键抑制语义）字段不变。

## 异常场景

- 抽屉关闭（X / Escape / 遮罩）→ `onClose` 置 `helpModalOpen=false`，快捷键恢复。

## 性能与安全

- 性能：markdown 轻量渲染（不引重库），子集为标题/段落/行内 `code`/`**bold**`/无序列表/围栏代码块。
- 安全/权限：帮助内容为纯展示，无设备/文件访问；正文为本地静态 markdown，不经跨端 RPC。

## 风险与回滚

- 风险：抽屉 portal 的主题色 CSS 变量注入需覆盖；「快捷键抑制」语义依赖 `helpModalOpen` 字段（未改名）。
- 回滚：改回 `Modal` 或移除 `HelpDrawer` 引用即可，改动集中在 `packages/ui` + `e2e-web`，不涉协议/跨端。
