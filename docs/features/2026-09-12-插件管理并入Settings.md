# 插件管理并入 Settings（删除独立 Plugin Manager 入口）

> 日期：2026-09-12　状态：完成
> 关联决策：ADR-038（插件安装入口）/ ADR-044（插件可执行化：卸载 + 隔离）/ ADR-045（随包插件一次性安装与「Restore bundled」）/ ADR-039（插件 `settings` 贡献分区）
> 前置：`docs/features/2026-09-12-Settings改抽屉.md`（Settings 已为右侧 Drawer）

## 需求摘要

删除独立的「Plugin Manager」弹窗入口（顶栏按钮 + 窄窗口 `More` 下拉项），把插件管理（安装 / 启用 / 禁用 / 卸载 / 恢复 Bundled / 加载错误展示）整体并入 Settings 抽屉，Settings 内含 `General` / `Plugins` 两个页签。

## 边界条件

- 入口唯一化：插件管理仅经 **Settings → Plugins** 进入；原先两处入口（顶栏按钮、窄窗口 `More` 项）全部移除。经核实**侧边栏从未有该按钮**，故无侧边栏改动。
- Settings 的 `General` 页签内容与顺序**零改动**（主题浅/深、主题色预设、语言、重置工作区、工作区导入导出、关于）。
- 插件 `settings` 贡献分区（ADR-039，`data-testid="plugin-settings"`）归属 `Plugins` 页签（同域聚合）。
- 懒加载：`SettingsDrawer` 仍由 `MamepApp` 经 `React.lazy` + `useOpenedOnce(settingsModalOpen)` 门控；插件管理作为其静态子组件，随抽屉 chunk 加载（原独立 `PluginManagerModal` chunk 消失）。
- 隐藏文件 input（`pluginInstall === "upload"` 时）的 `data-testid="plugin-manifest-file-input"` 保留。

## 异常场景

- 安装/卸载确认继续走 `App.useApp().modal.confirm`（渲染到 body portal），在 Drawer 内行为不变；取消态语义不变（取消 JS 插件安装 → `runtime.dispose()` 关闭隔离线程）。
- 无插件时显示 `Empty`（`plugins.empty`）；有加载错误时在页签尾部署名错误区（`plugins.loadErrors`）。
- `pluginInstall === "unsupported"` 时点击安装仍报 `plugins.installUnsupported`（能力矩阵判定不变）。
- 关闭 Settings 抽屉（关闭按钮 / `Esc` / 点遮罩）行为与改造前一致；抽屉关闭后根元素仍在 DOM 且需等离场动画（既有踩坑）。

## 性能与安全

- 首屏不变（Settings 仍懒加载）；分包结果：共用 UI 仍无 > 500 kB chunk（不自定义 `codeSplitting.groups`，遵循 2026-09-11 构建代码分割结论）。
- 安全边界零改动：插件安装的 §6.10.4 安全确认、隔离 Worker 执行、权限标签展示全部原样保留；不新增任何插件执行路径。

## 计划（Plan 摘要）

1. `PluginManagerSection`：<Space> 内「操作行（Restore bundled / Install Plugin）→ 插件列表（Switch 启用 + installed 卸载按钮）→ 加载错误 → 隐藏文件 input」。
2. `SettingsDrawer`：`Tabs`（首个页签默认 `General`）；`Plugins` 页签 = `<PluginManagerSection />` + 插件 settings 贡献分区。
3. `MamepApp` 删三处（按钮 / More 项 / 懒加载与渲染）并删 `setPluginModalOpen` 引用。
4. `app-store` / `guards` 收敛状态；有状态消费方与测试同步。
5. i18n 删死键、增页签键；帮助文案同步。
6. e2e 助手 `openPluginsTab(page)`（限定 `.settings-drawer` 作用域，antd v6 活动面板 `.ant-tabs-content-active`）。

## 风险与回滚

- 风险：
  - e2e 助手涉及 6 个 spec，需逐个实测；
  - 页面同时存在多组 antd `Tabs`（表格页签 / 底部面板 / Help 抽屉），Settings 页签定位**必须限定 `.settings-drawer` 作用域**；
  - 分包变化（少 1 个 chunk），构建后需核对无 > 500 kB 告警。
- 回滚：纯 UI 层入口整合，无数据 / schema / 协议 / 能力矩阵变更，单次提交可整体回退。
