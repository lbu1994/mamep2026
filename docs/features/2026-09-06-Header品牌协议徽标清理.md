# Header 品牌/模式指示清理（删除非 Mock 模式「Modbus RTU」徽标）

> 日期：2026-09-06　状态：完成
> 关联：`?mockTransport=1` dev 模式判定（MamepApp Header）。纯展示清理，无新增 ADR、不影响任何逻辑。

## 需求摘要

三端左上角「Mamep2026」右侧原本显示「Mock」徽标的位置，在非 Mock 模式下会显示「Modbus RTU」。目标：删除非 Mock 模式下的「Modbus RTU」显示，改为什么都不显示；Mock 模式保留「Mock」徽标不变。

## 边界条件

| 场景                                                                   | 现状              | 期望             |
| ---------------------------------------------------------------------- | ----------------- | ---------------- |
| Mock 模式（`?mockTransport=1`，`host.isMockMode === true`）            | 显示 `MOCK`       | **保持不变**     |
| 非 Mock 模式（浏览器普通 / Electron / VSCode，`isMockMode === false`） | 显示 `Modbus RTU` | **什么都不显示** |
| `host` 为 `null`/`undefined`（原逻辑回退渲染 `Modbus RTU`）            | 显示 `Modbus RTU` | **什么都不显示** |

## 异常场景

无。纯 JSX 条件渲染改动，不涉及连接/协议/调度/持久化任何运行时逻辑。

## 性能与安全

无影响。仅移除一个静态徽标，无新增渲染、无副作用、无协议或权限路径变更。

## 影响模块

| 包/端       | 文件                | 改动原因                                                                                                 |
| ----------- | ------------------- | -------------------------------------------------------------------------------------------------------- |
| packages/ui | `src/MamepApp.tsx`  | `mamep-header__protocol` 由「mock 渲染 MOCK / 非 mock 渲染 app.protocol」改为「仅在 mock 模式渲染 MOCK」 |
| packages/ui | `src/i18n/index.ts` | 删除 `app.protocol`（en + zh 各一处）——Header 移除后无任何引用，成为死键，一并清理                       |

## 计划（Plan 摘要）

1. `MamepApp.tsx`：`mamep-header__protocol` 渲染条件改为 `host?.isMockMode` 为真时才渲染（保留原 `host` 空值守卫）。
2. `i18n/index.ts`：删除 `app.protocol` 键（en/zh）。

## 测试策略

- 按用户决策**不补测试**。
- 已全仓检索确认无任何单测/e2e 断言 Header 显示「Modbus RTU」，改动不破坏既有断言。
- 回归（供知悉，执行时机由用户决定，docs/AGENTS.md §27）：`pnpm --filter @mamep2026/ui typecheck` / `lint`，或 mock 冒烟。

## 风险与回滚

- 风险：极低。`app.protocol` 若在别处被引用会编译报错，已全仓检索确认无其他使用者；`TranslationResources = typeof en`，en/zh 同步删除键保持一致。
- 回滚：还原 `MamepApp.tsx` 的徽标渲染逻辑与 `i18n` 的 `app.protocol` 键即可；改动集中在 `packages/ui`，不涉协议/跨端。
