# Bug 修复

本 Skill 是 Mamep2026 Bug 修复的 Codex 显式入口。用户提供的现象或复现步骤位于调用参数中；信息不足时先询问。

1. 完整读取 [dev-workflow](../dev-workflow/SKILL.md)，遵守其中的项目约束和测试时机。
2. 先做根因分析，区分根因与症状，列出触发条件和影响范围；输出后暂停等待确认。
3. 编写最小复现测试。只有在用户已授权执行测试时才运行并确认其失败；未授权时先说明并请求执行许可，不得谎称测试已失败。
4. 输出修复计划并暂停，等待用户明确回复「计划通过」。
5. 计划通过后按共享工作流完成文档、修复和回归。

在根因或复现条件不成立前不得凭症状直接修补。
