# 回归验证

本 Skill 是 Mamep2026 回归验证的 Codex 显式入口。用户指定的变更范围位于调用参数中；未提供时先从当前工作区变更判断。

1. 根据 `packages/*` 分层、应用依赖和测试覆盖定位受影响范围。
2. 先列出拟执行的受影响包单测、`pnpm typecheck`、`pnpm lint`；涉及界面或传输时补充冒烟或相关 e2e。
3. 执行前征求用户同意。只有用户明确要求执行，或已对本次调用授权运行，才可启动命令。
4. 输出通过数/总数、失败项、未执行项及原因，不得把计划执行写成已执行。

本 Skill 负责验证，不顺带修改失败代码；需要修复时先汇报并取得授权。
