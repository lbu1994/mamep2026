# 时钟与标识设计

## 1. 时间与时钟设计

所有领域时间通过 ClockPort 获取。

禁止在需要测试的调度逻辑中直接散落调用：

- Date.now；
- performance.now；
- setTimeout；
- setInterval。

ClockPort 提供：

- wallNow；
- monotonicNow；
- delay；
- schedule；
- cancel。

用途：

- 日志时间使用 wall clock；
- 超时和耗时使用 monotonic clock；
- 测试使用 Virtual Clock；
- 写后回读延迟可取消；
- 轮询不依赖不可控的真实等待。

系统时间被用户修改时，不应影响请求超时判断。

---

## 2. ID 设计

所有持久实体和运行时操作使用稳定 ID。

持久 ID：

- workspaceId；
- sheetId；
- rowId；
- connectionProfileId；
- pluginId。

运行时 ID：

- connectionId；
- requestId；
- attemptId；
- batchId；
- operationGroupId；
- cancellationId。

持久 ID 在保存和恢复后保持。

运行时 ID 不进入工作区，除非作为历史日志字段。

ID 通过 IdGeneratorPort 创建，测试中使用可预测 ID。
