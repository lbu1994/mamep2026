## 22. 平台通信桥设计

### 22.1 统一 Host API

共享 UI 通过 MamepHostApi 与平台通信。

主要能力：

- getCapabilities；
- listSerialPorts（后续版本 Electron/VSCode 枚举实现；MVP 阶段 Browser 与 Electron 均由授权 picker 承担，不实现，ADR-017）；
- requestSerialPort；
- connect；
- disconnect；
- executeCommand；
- loadWorkspace；
- saveWorkspace；
- listPlugins；
- enablePlugin；
- disablePlugin；
- subscribeEvents；
- exportData；
- importData。

Browser Host 可以在同一线程直接实现该接口。

Electron 和 VSCode 使用消息桥实现。

### 22.2 消息协议

所有跨边界消息使用版本化 Envelope：

    HostMessage
      protocolVersion
      messageId
      kind
      payload

消息类型分为：

- request；
- response；
- event；
- error。

要求：

1. 每条请求有唯一 messageId；
2. 响应引用原 messageId；
3. payload 使用 Zod 校验；
4. 未知 kind 被拒绝；
5. 不允许任意方法名调用；
6. 支持取消长任务；
7. 支持连接、日志和进度事件；
8. 消息协议版本可演进；
9. 错误通过结构化对象传递；
10. Uint8Array 采用明确可序列化格式传输。

> 多寄存器（ADR-030，2026-08-27 设计确认）：不加新 kind，扩展既有 payload 字段——
> `registerRowPayloadSchema` 增 `registerCount`（+ "string" 类型）、`batchReadRowPayloadSchema`
> 增 `quantity`、`poll-result` 结果支持 `values[]`、`writeOutcomePayloadSchema` verify 字段数组化；
> 三端 AppHost 已收整行对象天然透传。

### 37.4 请求结果

    type RequestResult<T> =
      | {
          ok: true;
          value: T;
          timing: RequestTiming;
          attemptCount: number;
        }
      | {
          ok: false;
          error: MamepError;
          timing: RequestTiming;
          attemptCount: number;
        };

    type WriteOperationResult =
      | {

        }

        }

        }
      | {
