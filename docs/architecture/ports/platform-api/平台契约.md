# 平台统一接口与消息契约

## 1. packages/platform-api

定义 UI 和 Application 层可访问的平台统一接口，包括：

- 串口；
- TCP；
- 持久化；
- 文件选择；
- 剪贴板；
- 通知；
- 插件；
- 平台信息；
- 能力矩阵；
- 生命周期。


## 2. 平台通信桥设计

### 2.1 统一 Host API

共享 UI 通过 MamepHostApi 与平台通信。

主要能力：

- getCapabilities；
- enumerateSerialPorts（Browser 以授权 picker 承担；Electron Web Serial 转发的端口列表和 VSCode Node Serial 系统枚举使用该能力语义）；
- requestSerialPort；
- connect；
- disconnect；
- executeCommand；
- loadWorkspace；
- saveWorkspace；
- listPlugins；
- enablePlugin；
- disablePlugin；
- subscribeEvents；
- exportData；
- importData。

Browser Host 可以在同一线程直接实现该接口。

Electron 和 VSCode 使用消息桥实现。

### 2.2 消息协议

所有跨边界消息使用版本化 Envelope：

    HostMessage
      protocolVersion
      messageId
      type
      kind
      payload

消息类型分为：

- request；
- response；
- event；
- error。

要求：

1. 每条请求有唯一 messageId；
2. 响应引用原 messageId；
3. payload 使用 Zod 校验；
4. 未知 kind 被拒绝；
5. 不允许任意方法名调用；
6. 支持取消长任务；
7. 支持连接、日志和进度事件；
8. 消息协议版本可演进；
9. 错误通过结构化对象传递；
10. Uint8Array 采用明确可序列化格式传输。

HostMessage v1 由 Electron 和 VSCode 共用。`type` 为 `request | response | event | error`，响应的 `messageId` 必须引用原请求。错误投影只传递可序列化字段，不把 `Error` 实例、函数、句柄或循环引用跨边界传递。

Electron IPC 使用独立频道：

- invoke 通道：`mamep:invoke`；
- event 通道：`mamep:event`。

Preload 不暴露通用 `ipcRenderer.invoke` 或任意 channel 名称，只暴露版本化 `MamepHostApi` 的语义方法。Main 与 Preload 都必须把消息视为不可信输入，Main 的 Zod 和 kind 白名单是最终校验边界。`debug:get-state` 只允许开发或测试探针使用，打包应用必须返回明确的禁用错误。

> 多寄存器（ADR-030，2026-08-27 设计确认）：不加新 kind，扩展既有 payload 字段——
> `registerRowPayloadSchema` 增 `registerCount`（+ "string" 类型）、`batchReadRowPayloadSchema`
> 增 `quantity`、`poll-result` 结果支持 `values[]`、`writeOutcomePayloadSchema` verify 字段数组化；
> 三端 AppHost 已收整行对象天然透传。


## 3. 数据契约示例

本节仅用于明确数据边界，不代表完整实现代码。

### 3.1 读取命令

    type ReadHoldingRegisterCommand = {
      requestId: string;
      connectionId: string;
      source: RequestSource;
      slaveAddressOrUnitId: number;
      registerAddress: number;
      timeoutMs: number;
      retryCount: number;
      cancellationId: string;
    };

### 3.2 写入命令

    type WriteHoldingRegisterCommand = {
      requestId: string;
      connectionId: string;
      source: RequestSource;
      slaveAddressOrUnitId: number;
      registerAddress: number;
      rawValue: number;
      timeoutMs: number;
      retryCount: number;
      verify: ReadVerifyPolicy;
      cancellationId: string;
    };

### 3.3 平台能力

    type PlatformCapabilities = {
      platform: "browser" | "electron" | "vscode" | "android";
      supportsRtu: boolean;
      supportsTcp: boolean;
      supportsSerialEnumeration: boolean;
      supportsFileSystem: boolean;
      supportsHostPlugins: boolean;
      supportsWorkspaceFiles: boolean;
      supportedSerialOptions: {
        dataBits: number[];
        stopBits: number[];
        parity: string[];
        flowControl: string[];
      };
    };

### 3.4 请求结果

    type RequestResult<T> =
      | {
          ok: true;
          value: T;
          timing: RequestTiming;
          attemptCount: number;
        }
      | {
          ok: false;
          error: MamepError;
          timing: RequestTiming;
          attemptCount: number;
        };

### 3.5 写后回读结果

    type WriteOperationResult =
      | {
          kind: "write-failed";
          error: MamepError;
        }
      | {
          kind: "write-succeeded-no-verify";
          writtenValue: number;
        }
      | {
          kind: "write-succeeded-verify-matched";
          writtenValue: number;
          readValue: number;
        }
      | {
          kind: "write-succeeded-verify-mismatched";
          writtenValue: number;
          readValue: number;
        }
      | {
          kind: "write-succeeded-verify-failed";
          writtenValue: number;
          verifyError: MamepError;
        }
      | {
          kind: "cancelled-before-verify";
          writtenValue: number;
        };
