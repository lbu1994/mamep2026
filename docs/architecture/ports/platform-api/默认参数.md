# 推荐默认技术参数

## 1. 推荐默认技术参数

以下参数是技术实现的初始默认值，不替代产品决策，可在原型后调整。

### 1.1 通信参数

- RTU 波特率：9600；
- 数据位：8；
- 停止位：1；
- 校验位：None；
- 流控：OFF；
- 请求超时：50 ms；
- 重试次数：1；
- 相邻请求之间无额外 Rx Delay；
- TCP 端口：502；
- TCP 连接超时：5000 ms；
- 启动状态：离线；
- 自动重连：默认关闭，仅 TCP 可按 profile 开启；
- 自动重连最大尝试：5 次；
- 自动重连退避基值：1000 ms；
- 自动重连退避上限：15000 ms。

### 1.2 轮询参数

- 轮询间隔固定为 0，读完一个目标后立即处理下一个目标；
- 每行最多一个等待中的轮询任务；
- 同一连接并发请求数：1；
- 轮询任务优先级低于用户手动读写；
- 页面或 Host 停止时取消所有后续轮询；
- 恢复工作区后不自动启动实际轮询。

### 1.3 日志参数

- 内存中的通信日志默认上限：10000 条；
- 应用消息默认上限：2000 条；
- 达到上限后删除最旧记录；
- 默认开启自动滚动；
- 用户手动滚动离开底部后暂停自动滚动；
- 导出默认使用 UTF-8；
- 原始报文使用大写十六进制字节串。

### 1.4 自动保存参数

- 普通编辑保存 debounce：500 ms；
- 标签页关闭或结构变更后立即安排保存；
- 同一时刻最多执行一个保存任务；
- 保存过程中发生新变更时，在当前保存完成后保存最新快照；
- Electron 至少保留一个最近有效备份；
- 保存失败后不丢弃内存中的未保存状态。

这些参数应集中定义，不得散落在 UI 和平台代码中。

### 1.5 表格与界面参数

- 地址列默认进制：DEC，按表独立；
- 新建寄存器表默认行数：50；
- 地址内部范围：0–65535；
- 默认语言：`en-US`，可选 `zh-CN`；
- TM 缓冲 Continue 硬上限：10000 条；
- Trace Speed 范围：100–2000 ms。
