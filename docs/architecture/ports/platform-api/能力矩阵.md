# 平台能力矩阵

## 1. 平台能力矩阵

平台不支持的能力应由能力矩阵明确表示。

建议定义以下能力：

| 能力                        |                             Browser |                            Electron |                              VSCode |                                                              Android |
| --------------------------- | ----------------------------------: | ----------------------------------: | ----------------------------------: | ------------------------------------------------------------------: |
| Modbus RTU                  |                                支持 |                                支持 |                                支持 |                                 支持（USB Host + usb-serial-for-android） |
| Modbus TCP                  |                              不支持 |                                支持 |                                支持 |                                                   支持（原生 socket） |
| 串口枚举                    |        授权 picker 承担，无全量枚举 |                     主进程枚举 + 渲染进程选择 |                                支持 |                       支持（USB Host 枚举；无 Web Serial 手势约束） |
| COM10 及以上                |            由浏览器设备选择机制处理 |                                支持 |                                支持 |                             支持（USB 设备制，无 Windows 路径问题） |
| 本地文件系统                |                                受限 |                                支持 |                                支持 |                                 受限（IndexedDB；暂不支持文件通道） |
| 系统剪贴板                  |           支持（需安全上下文/权限） |                                支持 |                                支持 |                                                               支持 |
| 工作区导入                  |                  客户端上传 / 解析 |                        文件对话框读取 |                        文件对话框读取 |                                                   暂不支持 |
| 工作区导出                  |                          浏览器下载 |                            保存对话框 |                            保存对话框 |                                                   暂不支持 |
| IndexedDB                   |                                支持 |                              非默认 |                              非默认 |                                            支持（WebView 原生支持） |
| Node.js 插件                |                              不支持 |                            受控支持 |                            受控支持 |                                                              不支持 |
| Web 插件                    |                        支持受限插件 |                              可支持 |                              可支持 |                       支持受限插件（手动安装；执行能力运行时探测） |
| 可执行插件                  |                   支持 Worker 隔离 |                  支持隔离及显式同进程 |                  支持隔离及显式同进程 |                                 运行时探测 Worker，失败则关闭 |
| Host 插件                   |                              不支持 |                                支持 |                                支持 |                                                              不支持 |
| 插件安装                    |                          客户端上传 |                            文件对话框 |                            文件对话框 |                                                   客户端上传 |
| 前后台生命周期              |                                支持 |                              不驱动远程会话 |                              不驱动远程会话 |                        支持（Capacitor App 状态桥） |
| 屏幕常亮                    |                              不支持 |                              不支持 |                              不支持 |                                                               支持 |
| 硬件返回键                  |                              不支持 |                              不支持 |                              不支持 |                                             支持（装配 App 桥时） |
| 协议 / 表类型扩展贡献       |                              受控支持 |                        受控支持 |                        受控支持 |                                                      受控支持 |
| VSCode 命令                 |                              不支持 |                              不支持 |                                支持 |                                                              不适用 |
| 系统通知                    |                          浏览器能力 |                                支持 |                         VSCode 通知 |                                                              不支持 |
| 分发与更新                  |                              不适用 |                            手动分发 |                      由 VSCode 管理 |                  手动分发；支持 Release APK/AAB 构建与可选签名 |

浏览器使用 Web Serial RTU、IndexedDB 和授权 picker，不开放直接 Modbus TCP。Electron
RTU 使用 Renderer Web Serial，TCP 会话在 Main；VSCode RTU/TCP 都在 Extension Host。
Connection Settings 依据 `modbusTcp` 能力显示协议入口，浏览器不出现必然失败的 TCP 表单。

`config/connections.json` 仅用于真实端口测试、探针和验证脚本，不是平台能力或用户可见的
连接配置入口。应用连接对象通过工作区 `connectionProfiles` 持久化，跨端交换使用工作区导入导出。

多寄存器连续读写是共享协议与通信能力，不新增平台能力字段；三端和 Android 通过共享范围行
语义使用同一协议实现。平台不支持的能力仍由本矩阵显式声明。

核心表类型固定包含保持寄存器、线圈、离散输入和输入寄存器。保持寄存器使用
FC03/FC0x10；线圈使用 FC01/FC0F；离散输入和输入寄存器分别使用 FC02/FC04
且只读。核心基础表 codec 支持 RTU；Electron、VSCode、Android 还通过共享
`TcpSessionHost` 支持基础表 TCP 请求。基础表协议 ID 不随承载变化，TCP 由
`BasicTablesTcpCodec` 封装 MBAP。浏览器只声明 RTU 能力。

`protocolExtensions` 与 `tableTypes` 是动态能力：静态基础值只保留核心 codec 和
四个核心表类型，实际列表在读取时叠加当前已启用且激活成功的插件贡献。插件
禁用、卸载或加载失败后，相应能力必须消失。不能在平台常量中硬编码安川或自定义
功能码插件能力。

Electron 工作区由主进程应用数据目录中的版本化 JSON 持久化，使用原子替换、单份 `.bak` 和损坏
自愈，`filesystem` 为 `"full"`。Renderer 只经
`workspace-load/workspace-save/workspace-clear/workspace-create-backup`
薄桥访问；文件路径与权限不离开 Main。浏览器仍以 IndexedDB 持久化并声明 `"limited"`；
VSCode 的通用 `filesystem` 能力仍为 `"unsupported"`，其工作区持久化位置以 VSCode 宿主文档为准。

能力矩阵通过 PlatformCapabilities 对象注入 UI。`clipboard`、`backgroundLifecycle`、
`keepAwake`、`hardwareBack` 与通信、文件、插件能力一样是显式声明；UI 不得通过可选方法
存在性或捕获运行时异常推断能力。生命周期桥未装配时，即使能力位允许，也必须由
`PlatformLifecycleHost` 的可选方法安全降级。

> **Android 列**：Android 为第四平台（Capacitor 容器 + 原生通信插件）。
> 已支持 Modbus TCP、USB-RS485、插件上传安装和 Web 插件。静态能力为
> `modbusRtu:true` / `serialPorts:"enumerated"` / `modbusTcp:true` / `filesystem:"limited"` /
> `nodePlugins:false` / `webPlugins:true` / `hostPlugins:false` / `pluginInstall:"upload"`。
> `executablePlugins` 以 `false` 为 fail-closed 基线，Android Host 构造前通过生产同路径 Blob Worker
> 探测覆盖；探测超时、失败或异常时保持 `false`，且只覆盖该字段。
> `logExport` / `workspaceImport` / `workspaceExport` 在文件通道落地后按实翻转。
>
> Android 默认请求超时和重试只在该平台 composition root 覆盖为 300 ms / 2 次，
> 不修改全局默认值；USB 和 TCP 仍使用共享会话、调度和协议编解码。

> **边界不变**：`browserCapabilities.modbusTcp` 维持 `false`（Android 与浏览器使用独立产物与独立能力矩阵）；
> Android 的 `AppHost.browserCompatibility` 返回 `null`（不使用 Web Serial 兼容性提示）。

UI 根据能力执行：

1. 隐藏完全不适用的功能；
2. 禁用临时不可用的功能；
3. 展示禁用原因；
4. 不尝试调用不存在的平台 API；
5. 不通过捕获运行时异常来判断平台能力。
