# 传输端口契约

## 1. 传输层设计

### 1.1 TransportPort

统一传输接口表达：

- open；
- close；
- write；
- subscribeData；
- subscribeError；
- subscribeClose；
- isOpen；
- capabilities。

TransportPort 只处理字节和连接事件，不理解寄存器行、Data Type 或工作区。

RTU 和 TCP 可以使用不同的 Transport 配置，但应向 CommunicationSession 提供统一的字节传输能力。

实现标识（`TransportPort.kind`）：`"web-serial"`（浏览器 / Electron Renderer）、`"node-serial"`（Node Serial Adapter）、
`"node-tcp"`（Node TCP Adapter）、**`"capacitor-serial"` / `"capacitor-tcp"`（Android）**、`"mock"`（dev）、`"fake"`（测试）。

> Android 端接缝切在 **TransportPort（字节流）**，不在功能码层：原生插件只提供「打开 / 写字节 / 来字节 / 关闭」，
> 帧编码、CRC、TCP 分帧、超时重试与会话编排全部留在共享 JS 层。
