# 插件契约与架构

## 1. packages/plugin-api

包含：

- 插件 Manifest Schema；
- 插件生命周期接口；
- 插件贡献点；
- 插件权限声明；
- 平台能力要求；
- 版本兼容规则；
- 插件 Host 接口；
- 插件错误边界。


## 2. 插件架构

### 2.1 设计原则

1. 插件不直接修改核心源代码；
2. 插件只通过稳定贡献点扩展；
3. 插件必须声明平台支持；
4. 插件必须声明权限；
5. 单个插件失败不能导致核心应用失败；
6. 插件不能绕过统一通信队列；
7. 插件不能直接取得底层串口句柄；
8. 插件通信请求必须生成日志；
9. 插件配置必须拥有独立命名空间；
10. 插件 API 采用版本化设计。

### 2.2 插件类型

定义两类插件：

#### UI-safe 插件

可在三端运行，能力受限。

适合：

- 数据显示类型；
- 工具面板；
- 文档和寄存器手册；
- 地址显示；
- 纯计算工具；
- 受控命令按钮。

不得执行任意 Node.js 代码。

#### Host 插件

仅在 Electron 或 VSCode Host 中运行。

适合：

- 厂商私有协议；
- 特殊通信封装；
- 本地文件处理；
- 受控设备操作。

Host 插件需要更严格的安装、权限和兼容性控制。

浏览器端不加载 Host 插件。

### 2.3 MVP 插件装载范围

> 已确认（2026-08-23，PRD §20.6）：MVP 仅预留架构、不对用户开放插件安装能力——维持「内置 / 受信任」边界（Manifest 驱动启停、错误隔离、平台能力声明已具备），浏览器端已有最小插件注册表保留为内部扩展验证；本地安装、安川示例插件、插件开发文档均延后到 V1.0 评估。

为降低任意代码执行风险，MVP 优先支持：

1. 随应用构建的内置插件；
2. 开发模式下的受信任本地插件；
3. Manifest 驱动的启用和禁用；
4. 插件加载错误隔离；
5. 平台能力检查；
6. 插件贡献点注册。

不在 MVP 默认开放从互联网下载并执行任意第三方插件。

### 2.4 Manifest

插件 Manifest 至少包含：

    PluginManifest
      id
      name
      version
      apiVersion
      author
      description
      license
      entry
      supportedPlatforms
      requiredCapabilities
      permissions
      contributes

permissions 可能包括：

- communication；
- workspace-read；
- workspace-write；
- file-read；
- file-write；
- network；
- ui-contribution。

MVP 不一定开放所有权限，但 Schema 应预留明确扩展方式。

### 2.5 贡献点

建议支持：

- command；
- toolbarAction；
- sidebarView；
- bottomPanel；
- contextMenu；
- dataType；
- addressTransform；
- protocolExtension；
- documentation；
- settings。

插件按钮执行后调用受控 command，不直接访问 UI 内部 Store。

### 2.6 通信能力

插件发起通信时必须通过 PluginCommunicationApi。

该 API：

- 校验插件权限；
- 校验当前平台；
- 创建 source 为 plugin 的请求；
- 进入统一 RequestScheduler；
- 记录 pluginId；
- 应用超时和取消；
- 不暴露 Transport；
- 不允许插件自行并发写串口。

### 2.7 插件错误隔离

插件 Hook 执行时：

1. 设置独立错误边界；
2. 捕获同步和异步异常；
3. 记录 pluginId；
4. 禁用故障贡献点；
5. 保持核心工作区可用；
6. 向用户展示可理解的加载失败原因；
7. 不因单个插件失败阻止其他插件加载。

### 2.8 插件版本兼容

插件声明 apiVersion。

Host 根据兼容范围决定：

- 可加载；
- 可加载但警告；
- 禁止加载。

插件 API 的破坏性修改必须提升主版本，并通过适配层保留必要的过渡期。

## 3. 插件原型

验证：

- Manifest 解析；
- 插件启用和禁用；
- 平台能力声明；
- 工具栏贡献；
- 侧边栏贡献；
- 地址转换；
- 插件通信请求进入统一调度器；
- 插件异常隔离；
- Electron 和 VSCode Host 插件加载；
- 浏览器端拒绝不兼容插件；
- 插件 API 版本不兼容提示。
