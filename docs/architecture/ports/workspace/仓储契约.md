# 工作区仓储端口

## 1. Repository 接口

WorkspaceRepositoryPort 至少提供：

- load；
- save；
- reset；
- export；
- import；
- createBackup；
- getRecoveryInfo。

UI 不直接调用 IndexedDB 或文件系统。

所有实现必须遵守以下语义：

- `load` 返回经过当前 Schema 校验和迁移的工作区；首次启动无数据时返回空工作区；
- `save` 接收不可变、完整一致的工作区快照，平台实现负责串行持久化，失败不得删除内存数据；
- `clear/reset` 删除主数据及其备份；不得误删其他应用级资产；
- `export/import` 与工作区交换格式使用同一 Schema，导入失败不得覆盖现有数据；
- `createBackup` 与 `getRecoveryInfo` 暴露恢复边界，损坏主数据时优先尝试最近有效备份；
- 所有失败返回结构化 `MamepError`，保留 `category` 和 `userMessageKey`，不得吞掉异常；
- 运行时连接、Timer、任务、日志、撤销历史和平台句柄不得进入仓储数据。

浏览器、Electron 和 VSCode 可以选择不同物理存储，但共享相同的领域对象、版本与恢复语义。
具体适配差异由其平台适配文档定义。
