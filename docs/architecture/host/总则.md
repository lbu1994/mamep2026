# Host 层总则

## 1. Host 层

Host 是每个平台真正的运行入口：

- Browser Host；
- Electron Main Host；
- Electron Renderer Host；
- VSCode Extension Host；
- VSCode Webview Host；
- Android WebView Host（Capacitor 容器 + 原生通信插件）。

Host 负责装配具体适配器，不实现领域规则。

共享 UI 的 `AppHost` 由窄职责契约组合而成：工作区、通信、轮询、Trace、日志、剪贴板、
文件、插件和平台生命周期分别定义。平台 Host 按实际职责声明子契约；新增能力只影响对应
平台和子契约。移动端生命周期方法可以因运行环境缺少桥而缺席，但平台能力必须由能力矩阵
明确声明并由 UI 门控。
