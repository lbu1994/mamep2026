# 资源释放与生命周期

## 1. 资源释放设计

### 1.1 连接释放

断开连接时必须：

1. 停止接受新请求；
2. 取消队列；
3. 停止轮询；
4. 停止自动重连；
5. 取消超时和延迟 Timer；
6. 释放串口 Reader 和 Writer；
7. 关闭串口或 Socket；
8. 删除数据和错误监听器；
9. 清空帧缓冲；
10. 更新连接状态。

close 操作必须幂等。

### 1.2 页面和窗口释放

Browser 页面关闭或隐藏时：

- 页面关闭前尝试保存；
- 释放串口；
- 页面隐藏不默认断开，但应检测后台限速；
- 页面恢复后重新计算调度时间；
- 不补发后台积压的轮询任务。

Electron 窗口关闭时：

- Renderer 请求保存；
- Main Process 停止通信；
- 等待有限时间释放资源；
- 超时后记录诊断并继续退出；
- 不允许后台残留无界请求。

VSCode Webview 关闭时：

- UI 订阅释放；
- 是否保持连接由产品策略决定；
- MVP 建议 Webview 关闭时仍由 Extension Host 管理连接；
- Extension 停用或 VSCode 关闭时必须断开；
- 重新打开 Webview 时从 Host 获取当前状态快照。

### 1.3 插件释放

停用插件时：

- 禁止创建新命令；
- 取消插件待执行任务；
- 注销 UI 贡献；
- 注销事件监听；
- 清理插件 Timer；
- 调用 dispose；
- 插件 dispose 异常不得阻止其他资源释放。
