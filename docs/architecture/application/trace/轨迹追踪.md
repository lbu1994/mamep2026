# 轨迹追踪

## 1. 定位与职责

TM 表示轨迹追踪（Trace）。用户在当前寄存器行启用 TM 后打开 Memory Trace
窗口，对目标寄存器持续采样并保留本次会话的历史数据。

- `traceEnabled` 与 `pollingEnabled` 是两个独立字段，不得复用；
- `traceEnabled` 属于可恢复的工作区行配置；
- Trace 窗口、采样队列和本次采样历史属于运行时状态，不写入工作区；
- Trace 采样必须进入统一通信调度器，不得直接访问 Transport；
- Trace 采样来源是通信成功事件，不得直接监听 React State。

Trace 由 Application/Communication 编排、共享 UI 展示，核心采样逻辑不依赖
React、Electron 或 VSCode。

## 2. 采样模型

`TraceCoordinator` 按行维护独立采样任务，每个任务至少包含：

- 行标识 `key`；
- 寄存器地址 `address`；
- 连续寄存器数量 `quantity`；
- 采样间隔 `speedMs`；
- 请求路由 `route`；
- 单调时钟 Timer；
- 是否正在请求；
- 单调递增序号。

每个成功样本至少包含：

- `sequence`；
- `timestamp`；
- `key`；
- `rawValue`。

单寄存器直接记录 16 位原始值；范围行按大端组合为数值后采样。字符串类型等
无法形成明确数值的范围行由 UI 禁用 TM。

后续扩展可增加以下契约：

- `SampleEvent`；
- `TraceSession`；
- `TraceBuffer`；
- `TraceExporter`；
- `SampleSource`；
- `SamplingPolicy`。

## 3. 采样与调度

1. 采样只读取设备，不产生写请求；
2. 同一采样任务在上一请求完成前不重复发送，跳过本轮而不是积压；
3. 所有采样请求进入统一 RequestScheduler，优先级不高于用户手动操作；
4. 多行 Trace 可以并行存在，但同一连接上仍由调度器串行访问设备；
5. 协议路由与当前会话不兼容时，不启动采样并上报明确提示；
6. 断开连接、设备拔出、Host 停用或页面释放时停止 Trace；
7. 应用进入后台时应暂停持续占用总线的采样，回到前台后按原配置恢复；
8. 采样间隔使用 ClockPort/单调时钟，测量和调度不依赖墙钟时间。

## 4. 窗口与交互

Memory Trace 窗口至少提供：

- 标题；
- Play；
- Stop；
- Save；
- Buffer Size；
- Speed；
- `No./Data` 数据列表；
- Average；
- 关闭。

Speed 的有效范围为 100–2000 ms，数值越接近 Quick 采样间隔越短。
Buffer Size 提供固定档位和 Continue。

关闭 Trace 窗口后同步关闭对应行的 `traceEnabled`，避免 UI 开关与实际采样状态
分离。窗口位置属于纯界面运行时状态，重新打开后可以回到默认位置。

## 5. 缓冲、平均值与导出

Continue 档不得真正无限缓存，使用环形缓冲区并设系统硬上限 10000 条。
固定档位超过上限时同样截断最旧样本。

Average 规则：

- 默认基于寄存器原始数值或可明确定义的数值计算；
- HEX、Binary 等展示形式先还原为原始数值再参与计算；
- 无有效样本时不显示平均值；
- 缓冲发生截断时明确平均值对应的统计范围。

Save 导出当前会话的展示数据、平均值和寄存器信息。内部导出格式必须与普通
工作区持久化格式区分。

## 6. 生命周期

停止 Trace 时必须：

- 取消后续采样 Timer；
- 将任务移出活动 Trace 集合；
- 保留用户已经查看或导出的历史数据；
- 不影响其他行 Trace 和普通轮询；
- 不因一个 Trace 任务失败阻止其他调度任务。

重建会话时只恢复明确配置的活动 Trace；工作区恢复后应用仍保持离线，不自动
连接或自动开始采样。

## 7. 后续 Register Trace 边界

Memory Trace 的数据列表采样已经属于核心能力。Register Trace 的实时曲线、
长期历史、外部留存格式和是否由插件实现仍属于后续扩展边界。

扩展前需要确认：

- 是否允许多个 Register Trace 同时长期运行；
- Continue 或长周期模式是否改为流式写入文件；
- 曲线、降采样和导出格式；
- Trace 属于核心能力还是独立插件；
- 平均值、缺失样本和异常样本的统计语义。
