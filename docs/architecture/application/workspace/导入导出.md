# 工作区导入导出

## 1. 导入导出扩展预留

工作区的序列化、解析、Schema 校验和迁移由 `packages/workspace` 提供；平台文件选择与
读写通过 AppHost/HostMessage 完成。UI 只编排入口、预览和确认流程。

需要区分：

- 内部持久化格式；
- 公开工作区交换格式；
- CSV 寄存器表格式；
- 通信日志导出格式（CSV）；
- Trace 导出格式。

内部持久化格式可以包含 UI 状态。

公开交换格式应避免包含：

- 本机绝对路径；
- 临时连接 ID；
- 串口授权对象；
- 未声明的插件内部状态；
- 运行时错误；
- Timer 和任务状态。

CSV 导入导出不应直接成为领域数据源，必须先解析、校验并形成导入预览。

## 2. 当前导入导出决策

工作区交换使用版本化 UTF-8 JSON，且直接复用工作区 Schema 与迁移链。导出内容来自完整的
持久化工作区快照；导入执行 `JSON.parse → Schema 校验 → 顺序迁移 → 断链检测`，成功后替换
当前工作区。公开交换格式不包含连接句柄、协商后的串口授权对象、计时器、任务、运行时错误
或本机绝对路径。`recentPortHint` 等明确声明的提示字段可以保留。

入口位于 Settings，与 Reset Workspace 并列：

1. 导出先生成经文件名安全清洗的 `mamep-workspace-<name>-<YYYYMMDD-HHmmss>.json`，
   同时提供建议文件名和 `application/json` MIME 类型；
2. 导入先读取文本并校验，再预览工作区名称、表数、行数、连接数和 Schema 版本，明确提示
   本次操作将覆盖当前工作区；
3. 当前已有连接时不静默断开，也不拒绝导入；预览提示用户建议先断开，确认后仅替换工作区
   数据，连接生命周期仍由用户控制；
4. 用户取消、文件读取失败、JSON 错误、Schema 不支持或迁移断链都不得修改当前工作区；
5. 确认导入后清空撤销/重做历史，并把导入结果作为新的自动保存事实源。

确认提交分两阶段：当前任务替换工作区并提交表格首帧，下一任务再卸载确认 Modal。
这样 1000 行表的重建不会与 Modal DOM 清理合并成一次长任务；工作区替换仍是原子
Store 操作，取消发生在替换前时旧工作区保持有效。

平台文件能力按能力矩阵分支：

| 平台     | 导入                                   | 导出                                   |
| -------- | -------------------------------------- | -------------------------------------- |
| 浏览器   | 隐藏文件输入并读取 UTF-8 文本          | Blob 下载                              |
| Electron | `open-text-file` 系统文件对话框        | `save-text-file` 系统保存对话框        |
| VSCode   | `open-text-file` 系统文件对话框        | `save-text-file` 系统保存对话框        |
| Android  | 当前能力未开放时如实报告 `unsupported` | 当前能力未开放时如实报告 `unsupported` |

能力位为 `unsupported` 时，入口不得表现为点击后静默无操作。UI 必须显示 warning
级能力提示并停止后续文件调用；Android 当前的导入/导出提示复用工作区文件动作
的统一错误投影。只有能力已实现并通过平台门控时才可打开文件选择器或生成下载。

`open-text-file` 的请求可带建议文件名，响应为 `{ content: string | null }`；`null` 表示
用户取消而不是错误。导出复用 `save-text-file`，用响应中的 `saved` 区分保存和取消。
Electron/VSCode 不向 Webview 暴露任意路径或文件系统对象，所有文件访问均经白名单消息和
Schema 校验。

连接对象随工作区的 `connectionProfiles` 一起交换，不再提供独立的“从配置文件载入连接”
应用入口。仓库根 `config/connections.json` 仅供真实端口测试、探针和验证脚本读取，不属于
工作区交换格式。

系统原生文件对话框、取消和路径行为由各平台宿主适配；自动化可以替换对话框或文件端口，
但不得把测试桩的固定路径写入生产持久化逻辑。完整交换闭环至少覆盖跨平台 roundtrip、
覆盖预览、取消、坏文件、迁移和当前工作区不被破坏。

寄存器表 CSV 导入导出不属于当前产品能力，也不得直接成为领域数据源。
