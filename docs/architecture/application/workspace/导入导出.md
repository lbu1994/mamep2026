# 工作区导入导出

## 1. 导入导出扩展预留

工作区导入导出通过 WorkspaceSerializerPort 实现。

需要区分：

- 内部持久化格式；
- 公开工作区交换格式；
- CSV 寄存器表格式；
- 通信日志导出格式（CSV）；
- Trace 导出格式。

内部持久化格式可以包含 UI 状态。

公开交换格式应避免包含：

- 本机绝对路径；
- 临时连接 ID；
- 串口授权对象；
- 未声明的插件内部状态；
- 运行时错误；
- Timer 和任务状态。

CSV 导入导出不应直接成为领域数据源，必须先解析、校验并形成导入预览。

## 2. 当前导入导出决策

ADR-033 已确认版本化 JSON 工作区交换格式：

- 入口位于 Settings；
- 导入前读取、解析、校验并显示工作区摘要和覆盖风险；
- 公开交换格式复用工作区 Schema；
- 三端可以相互导入；
- 导入不会静默断开活动连接，而是提示用户先断开；
- 导出和导入的中断、取消和解析失败不得破坏当前工作区；
- 平台文件读写通过 AppHost 端口完成，UI 不直接访问文件系统；
- 浏览器使用上传/下载能力，Electron 和 VSCode 使用系统文件对话框。

寄存器表 CSV 导入导出仍属于后续扩展，不直接成为领域数据源。
