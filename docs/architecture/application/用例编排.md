# 应用用例编排

## 1. Application 层

包含用例和业务编排：

- 连接；
- 断开；
- 单行读取；
- 单行写入；
- 写后回读；
- 全表读取；
- 开始和停止轮询；
- 工作区加载与保存；
- 标签页管理；
- 插件启用与禁用；
- 日志导出；
- 状态恢复；
- 数据迁移。

Application 层通过 Ports 使用外部能力。

## 2. 共享会话编排

`SessionHostCore` 是浏览器、Electron 与 VSCode 共用的应用编排单元，组合：

- `CommunicationSession`；
- 请求调度与周期轮询；
- 批量读取与写后回读；
- Trace；
- 寄存器表地址/类型解析与表级配置；
- 设备拔出和连接中断策略；
- 活动批任务登记与取消。

协议的 Transport 打开方式由调用方注入，核心不依赖浏览器、Node、Electron 或 VSCode API。
`RtuSessionHost` 和 `TcpSessionHost` 只声明协议差异；远程 Host 复用同一核心并桥接
HostMessage，不复制业务规则。

一次写操作至少维护以下阶段边界：表单/行快照、地址与类型校验、写入、可选回读延迟、
回读比较和结果投影。断开、取消或设备拔出必须进入同一资源释放路径，未开始任务取消，
已发送任务的迟到结果不得更新新会话。
