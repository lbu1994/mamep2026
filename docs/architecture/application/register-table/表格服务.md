# 寄存器表应用服务

## 1. packages/register-table

包含：

- 表格应用服务；
- 行增删移动（含插入、批量移动、批量删除，`row-operations.ts`）；
- 复制和粘贴模型（含系统剪贴板 CSV 编解码与应用内剪贴板，`row-clipboard.ts`）；
- 多行选择状态（会话态 `selectedRowIds`，由 UI 层 Ant Design `rowSelection` 驱动）；
- 地址提交；
- 单元格直接编辑；
- 读取结果应用；
- 写入值解析与校验；
- 状态和错误投影；
- 撤销与重做命令（已实现，见 ADR-032；范围见本文 §2）；
- 对通信服务的用例封装。

行编辑使用 Ant Design Table 的 `rowSelection`、Dropdown 和受控输入能力。插入、移动、删除、复制、剪切和粘贴的状态语义位于 `register-table`，UI 只维护 `selectedRowIds` 等会话状态。多选不依赖 AntD 内部结构，右键菜单和快捷键都经 `app-store` 的统一动作执行。

## 2. 地址提交与按表进制

地址候选文本为 `addressDraft`，已提交起始地址为 `addressValue`，范围长度由 `registerCount` 表示。提交时必须传入所属表的 `registerRadix`，不能使用全局进制：

- DEC 接受十进制整数并校验 0–65535，提交后去除前导零，不补位；
- HEX 接受 1–4 位十六进制字符，不接受 `0x` 前缀，提交后补足 4 位大写；
- 范围文本两端使用同一表级进制解析，并验证结束地址大于或等于起始地址；
- 格式错误或超范围时保留 draft 并返回 `ADDRESS_OUT_OF_RANGE` 等结构化错误，不发送请求；
- 切换 DEC/HEX 不重排已提交文本，只影响列头、后续输入和值格式化。

复制表时继承源表 `registerRadix`；老工作区缺少该字段时默认 DEC，不需要提升 Schema 版本。UI 由 `RegisterTable` 按行所属表取得进制，不能从当前活动表推断其他表的设置。

## 3. 行操作

行操作统一位于 `row-operations.ts`：

1. 末尾追加或目标行之后插入空行，不继承名称、地址、类型或备注；
2. 目标行之前插入空行；
3. 按稳定 `rowId` 移动一个选择块；
4. 按稳定 `rowId` 删除一个选择块；
5. 每次结构变化后重新编号显示顺序，但不得改变 `rowId`。

多选集合 `selectedRowIds` 是会话状态，切换表或重置工作区时按 UI 规则清空，不写入持久化模型。右键菜单和键盘动作都调用同一 Store 命令，不复制业务逻辑。

删除操作不增加独立确认弹窗；现有点工具需要支持从撤销/重做栈恢复误删。删除正在轮询的行时必须取消后续轮询，并使迟到结果失效。

## 4. 剪贴板

`row-clipboard.ts` 定义平台无关的行块模型和 CSV 编解码：

- 系统剪贴板列固定为 `Name,Address,Data,Type,Comment`；
- Address 使用十进制整数，空地址留空；
- 使用 RFC4180 兼容的引号、逗号和换行转义；
- 解码按首列名兼容 `Name` 表头，新旧 CSV 均可导入；
- Address 粘贴后按目标表进制重新格式化；
- Data 非法文本原样保留，交给现有单元格解析和行级校验提示。

粘贴在目标行或最后选中行之后插入；无目标时追加表尾；空间不足时自动补空行，不静默截断。整个选择块的剪切或粘贴作为单个撤销步骤。

系统剪贴板经 `AppHost.copyTextToClipboard` / `readTextFromClipboard` 访问。写系统剪贴板失败不得清空应用内剪贴板；系统剪贴板读取失败时使用应用内最近行块。复制和剪切不修改设备状态，也不触发通信。

键盘处理只通过统一快捷键注册表分发。焦点位于文本输入、Select、单元格编辑器，或存在阻塞式 Modal/Drawer 时不得执行行快捷键。

## 5. 撤销与重做

撤销栈只处理工作区编辑操作：

- 新增行；
- 删除行；
- 修改名称；
- 修改地址；
- 修改 Type；
- 修改轮询设置；
- 粘贴；
- 移动行；
- 表级配置和表结构操作。

不撤销：

- 设备读取结果；
- Data 单元格文本修改；
- 已经发送的写入；
- 连接和断开；
- 通信日志；
- 设备产生的外部状态；
- Trace 窗口与采样历史；
- 列宽、列序和标签页打开/关闭等视图状态。

写入设备后不能使用普通 UI 撤销恢复设备值。一次批量删除、移动、剪切或粘贴
整体作为一个撤销步骤。撤销/重做栈属于纯内存会话状态，不随工作区持久化；
容量上限为 100 步，加载或重置工作区时清空历史。

实现和完整决策见
[ADR-032](../../../adr/ADR-032-撤销和重做.md)。
