# 前端状态管理

## 1. 状态管理

采用 Zustand 管理 UI 和应用层状态。

状态分为四类：

1. 领域持久状态；
2. 运行时连接状态；
3. 通信任务状态；
4. 纯界面状态。

### 1.1 领域持久状态

包括：

- 工作区；
- 标签页；
- 寄存器行；
- 通信配置；
- 轮询配置；
- 备注；
- 主题和布局设置；
- 插件启用配置。

这些状态通过工作区仓储保存。

### 1.2 运行时连接状态

包括：

- 当前连接状态；
- 当前连接 ID；
- 当前活动协议；
- 串口授权状态；
- 最近连接错误；
- 当前连接能力。

运行时连接状态不直接写入工作区。工作区仅保存允许恢复的配置。

### 1.3 通信任务状态

包括：

- 队列长度；
- 当前任务；
- 批量读取进度；
- 轮询运行状态；
- 取消状态；
- 当前重试次数；
- 实际轮询周期统计。

通信任务状态由通信服务提供，UI Store 只保存显示所需的投影。

### 1.4 纯界面状态

包括：

- 当前活动标签页；
- 侧边栏展开状态；
- 底部面板高度；
- 当前表格选择；
- 对话框状态；
- 筛选条件；
- 日志自动滚动状态。

纯界面状态不得反向驱动协议层的隐含行为。
