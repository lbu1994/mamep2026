# 样式与主题

## 1. 样式和主题

UI 组件框架统一采用 Ant Design，主题通过 ConfigProvider 主题令牌管理：

- Ant Design ConfigProvider token 体系；
- defaultAlgorithm 与 darkAlgorithm 切换浅色和深色主题；
- 基于 antd token 扩展的语义令牌；
- 平台主题适配层；
- @ant-design/icons 图标。

基于 antd token 扩展的语义令牌至少包括：

- 品牌强调色；
- 在线、警告、错误和离线语义色；
- 表格行高；
- 单元格边距；
- 焦点轮廓；
- 轮询和操作状态色。

VSCode 端通过主题适配层将 VSCode Theme Color 映射到 antd token，保持三端主题一致。

## 2. 默认主题色与派生规则

默认品牌色不保存浅色/深色十六进制字面量，而是在运行时通过 Ant Design 公开 API
`theme.getDesignToken({ algorithm })` 获取：

- 浅色使用 `defaultAlgorithm`；
- 深色使用 `darkAlgorithm`；
- Ant Design 升级默认色后应用自动跟随；
- 自定义 CSS 品牌变量映射 antd CSS 变量，不维护第二份色值。

禁止把已经派生后的颜色重新作为 `token.colorPrimary` 种子传回带 algorithm 的
`ConfigProvider`，否则会发生二次派生，导致 CSS 变量与实际渲染颜色不一致。

插件主题色只提供单一明亮主色种子；暗色主色、hover 和 active 由 antd 算法派生。
插件被禁用或卸载后，当前预设失效并回退默认色。VSCode 适配保留品牌/状态色，中性色
继续跟随编辑器主题。
