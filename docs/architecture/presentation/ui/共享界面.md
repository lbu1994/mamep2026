# 共享界面设计

## 1. packages/ui

包含三端共享的：

- 页面布局；
- 顶部应用栏；
- 侧边栏；
- 标签页；
- 寄存器表（含多行选择、行级右键菜单、行级键盘快捷键）；
- 连接配置；
- 日志面板；
- 插件页面；
- 设置页面；
- 通用组件；
- 快捷键注册表与两级键盘分发；
- 可访问性工具；
- UI Store。

## 2. 应用框架与入口

四端加载同一 React UI，平台差异只由 `AppHost`、能力矩阵和条件挂载的平台桥表达，不为某个平台维护第二份页面。

顶部应用栏承载连接设置、设置/插件管理和帮助等全局入口；侧边栏只负责寄存器表列表与打开/关闭状态，不重复承载全局设置入口。连接控制使用单个 CONNECT/DISCONNECT 切换按钮，连接忙态禁止重复触发；状态必须同时使用文字和语义色表达，不能只依赖色点。

Connection Settings 使用 Modal，承载协议、连接参数、串口选择和连接动作。只有当前连接参数和端口选择不足时才打开该 Modal 引导填写；参数已就绪时允许顶栏直接连接。连接失败应保留表单输入并显示结构化原因。

设置使用 Drawer。插件管理作为 Settings 的 Plugins 分区，不再维护独立 Plugin Manager 弹窗。移动端沿用同一信息架构，通过 Drawer 或“更多”面板收纳入口。

## 5. 表格列与选择

默认寄存器表的稳定列语义为：

- 多选复选框列，位于 No 列之前；
- No、TM、Name、Address、WP、READ、Data、WRITE、Type、Comment；
- 不提供独立 Status 列，行状态通过单元格、工具栏和消息反馈表达；
- READ/WRITE 使用带文字的按钮，不能只显示不可识别图标；
- Address 列头随当前表的进制显示 `Address[DEC]` 或 `Address[HEX]`。

多选使用 Ant Design Table `rowSelection` 原生能力，支持表头全选、Shift 范围选择和 Ctrl/Cmd 多选。应用状态只保存 `selectedRowIds`，该集合属于会话状态，不持久化，也不依赖 Ant Design 内部节点或索引。

地址列进制是 `RegisterSheet.registerRadix` 表级设置：

- 默认 `"dec"`，合法值为 `"dec" | "hex"`；
- 随工作区保存，各表互不影响，复制表继承源表设置；
- 切换值只改变列头和后续解析格式，不重排已提交的地址文本。

表格工具栏提供 DEC/HEX `Segmented` 控件。DEC 只接受十进制数字并限制在 0–65535；HEX 接受 1–4 位十六进制字符，不接受 `0x` 前缀，提交后规范为 4 位大写。超范围或格式错误返回结构化地址错误并保留用户输入。详细地址语义见 [数据类型转换设计](../../domain/data-conversion/转换设计.md)。

表格工具栏的从站地址控件使用活动表值：

- RTU 显示 `Slave Address`；
- TCP 显示 `Unit ID`；
- 两者范围均为 0–255，修改后对活动表后续读、写、轮询、批量和 Trace 生效；
- 标签、提示和 aria-label 按当前连接协议切换，不能只在视觉文本上改名而继续调用错误语义；
- 未连接时保留当前表配置，连接建立后由活动表值覆盖 profile 的初始地址。

### 范围行与展开子行

Address 支持 `start-end`，父行通过 `registerCount` 保存连续数量。`registerCount>1` 的行可展开为
每个寄存器一个子行：

- `registerValues` 是各原始值的单一事实源，父行 `cellText` 是组合解释后的显示/编辑文本；
- 子行 Name、Data、Type、Scale、Comment 可编辑并随工作区持久化；
- 子行 Data 编辑更新对应原始值并重算父行文本；父行或设备读取更新原始值后，子行按各自
  Type 重新格式化；
- 子行不得单独执行读写、轮询、拖拽、多选或右键行操作；写入统一由父行一次发送全部连续值；
- 展开子行是派生呈现，不复制持久化实体，行 Identity 与操作仍以父行 `rowId` 为准；
- 范围长度变化时按索引保留/截断子行元数据，原始值必须按协议边界重新校验，不能与旧范围错位。

## 6. 表格编辑呈现

Data 单元格使用受控 Input，编辑直接更新 Store 行数据：

1. 输入变化即时写入单元格当前值；
2. 无编辑会话、草稿或提交事务；
3. 读取成功结果无条件覆盖单元格内容，包括用户正在输入时；
4. 单元格值存放在 Store 行数据中，不随虚拟化卸载丢失；
5. 读取失败不修改单元格内容；
6. 写入校验失败不清空单元格内容；
7. Type 切换不改写单元格文本。

输入组件可以为本单元格编辑持有短暂显示草稿，但不得建立第二份“待写值”领域事实源。
立即提交（Enter、失焦或操作触发）必须读取同步维护的最新草稿，而不是依赖尚未刷新的
React render 闭包；否则快速输入、协同渲染或自动化 fill 后立即提交可能跳过修改。

设备读取、写入和回读的完整语义见
[全表读取与写后回读](../../application/communication/读写流程.md)。

## 7. 行编辑与剪贴板

行操作由 `register-table` 提供业务语义，UI 只调用 `app-store` 的统一动作：

- 在当前行上方或下方插入不继承字段的空行；
- 上移或下移当前选择块；
- 删除当前选择块；删除桌面端使用现有撤销/重做栈恢复误删；
- 复制、剪切和粘贴当前选择块；
- 行级右键菜单使用 Ant Design `Dropdown trigger={["contextMenu"]}`；
- 右键目标行必须包含在当前选择集合中。

系统剪贴板使用 UTF-8 CSV，表头为 `Name,Address,Data,Type,Comment`。Address 导出为十进制整数，避免把源表 HEX 文本粘贴到目标表时产生进制歧义；解码按首列名兼容新旧表头。RFC4180 规则处理逗号和换行转义。

应用内剪贴板跨标签页保留最近一次行块，是系统剪贴板不可用时的兜底。复制或剪切写系统剪贴板失败不得清除应用内剪贴板。

粘贴规则：

1. 插入到目标和最后选中行之后；无目标时追加到表尾；
2. 目标空间不足时自动补行，不得截断数据；
3. Address 按目标表 `registerRadix` 重新格式化；
4. 非法 Data 保留原始文本并形成行级校验问题，不得静默丢弃；
5. 整次粘贴作为一个撤销步骤。

键盘操作必须接入统一快捷键注册表。焦点位于文本框、Select、表格单元格编辑器或任一 Modal/Drawer 时，不执行表格全局快捷键。行快捷键至少覆盖复制、剪切、粘贴、插入、删除和选择块移动；键位以快捷键注册表和帮助界面为单一事实源。

### 快捷键注册表与两级分发

快捷键定义集中在共享 UI 的注册表中，单项至少包含稳定 `id`、`scope`、精确组合键、
帮助页展示文本和可选别名。动作说明的 i18n key 由 `id` 派生，帮助总览、App 级分发和表格级
分发读取同一注册表，禁止在按钮、帮助文本和事件处理器里各写一份。

当前 App 级键位：

| 操作 | 快捷键 |
| --- | --- |
| 打开 Settings | `Ctrl+,` |
| 连接/断开切换 | `Ctrl+Enter` |
| 打开帮助 | `Ctrl+/`，别名 `?` |
| 上一/下一标签页 | `Ctrl+[` / `Ctrl+]` |
| 新建/关闭表 | `Ctrl+Alt+N` / `Ctrl+Alt+W` |
| 导出/导入工作区 | `Ctrl+Shift+S` / `Ctrl+Alt+O` |
| 切换明暗主题 | `Ctrl+Alt+T` |
| 聚焦通信日志 | `Ctrl+Alt+L` |

当前表格级键位：

| 操作 | 快捷键 |
| --- | --- |
| 全表读取或取消 | `F9` |
| 读取选中行 | `F8` |
| 写入选中行 | `Ctrl+Shift+Enter` |
| 切换选中行轮询 | `Alt+P` |
| 上/下移动选中行 | `↑` / `↓` |
| 恢复列布局 | `Ctrl+Alt+R` |

再保留已有行编辑键：`Alt+↑/↓`、`Delete`、`Ctrl+C/X/V/I`、`Ctrl+Z/Y/Shift+Z`、
`Escape`、单元格 `Enter`/`Space`，以及 Ant Design Tabs/Menu 的原生导航。快捷键不得
占用浏览器或系统保留组合；macOS 使用 `Ctrl`/`Meta` 的平台 `mod` 语义，未声明的修饰键必须
不成立，使 `Ctrl+Enter` 与 `Ctrl+Shift+Enter` 可区分。

分发分两级：

1. App 级监听设置、连接、帮助、标签页、导入导出、主题和日志焦点，并调用既有 Store/宿主动作；
2. 表格级只作用于活动表和选中行，复用按钮路径的读行、写行和导入导出用例，不能在事件处理器
   中复制通信、序列化或轮询逻辑。

按键守卫由两级共用：文本输入、Select、单元格编辑器或 contenteditable 聚焦时不拦截；
方向键仅当焦点位于表格体且不在真正编辑控件内时移动行选择；任一 Modal/Drawer 打开时抑制
全部全局动作，避免与表单提交、确认或关闭冲突。帮助入口展示注册表内容，不另建手工维护的
说明列表。自定义键位重绑及持久化暂不提供；这些操作仍可通过 Tab、Enter、Space 和原生
组件键盘语义完成。

macOS 浏览器中的 `F8`/`F9` 可能需要同时按 `Fn`。部分 Windows 输入法会占用
`Ctrl+Alt+*` 组合；应用不探测或改写第三方输入法行为，但帮助界面必须保留准确键位。

## 8. 可访问性与可用性

可访问性要求：

- 所有图标按钮具有辅助文本；
- 表格使用适当的 ARIA 语义；
- 单元格错误与编辑器关联；
- 焦点状态清晰；
- 状态不只依赖颜色；
- 动态读取不抢夺焦点；
- 日志自动滚动可暂停；
- 频繁轮询使用非侵入式更新；
- 键盘可完成核心任务；
- 对话框具有焦点圈定和关闭后焦点恢复；
- 表格虚拟化不破坏屏幕阅读器的基础导航；
- 界面缩放后核心操作仍可使用。

可用性要求：

1. 首次使用者无需阅读完整帮助即可完成连接、填写地址和读取；
2. 高频操作直接位于主界面；
3. 输入项显示名称、单位、范围或示例；
4. 禁用操作说明原因；
5. 错误提示包含问题和可执行的解决方法；
6. 连接、读取、写入和轮询提供明确的进行中状态；
7. 长时间操作允许取消；
8. 操作失败后不得无提示清空用户输入；
9. 多端使用相同的名称、位置和行为语义；
10. 专业术语保持一致。

全表读取运行时显示明确 loading 和独立取消按钮。取消入口调用同一个 `BatchReadHandle.cancel`，
本地与远程路径对 UI 无差异；取消后等待的旧汇总不得覆盖重新发起的新批次状态。

## 9. 国际化

界面文案使用集中式资源键，业务层不拼接用户文案。共享 UI 内建 `en-US`（默认与回退语言）和 `zh-CN`；语言偏好随工作区持久化，并在首帧前通过启动缓存恢复。

要求：

- 错误使用 message key 和参数；
- 原始报文不翻译；
- Type 内部值不本地化；
- CSV 和工作区字段名不依赖界面语言；
- 时间可以通过平台 Locale 格式化；
- 数字协议转换使用固定规则，不使用本地显示格式作为协议输入；
- 通信术语在各语言中保持一致；
- 十六进制地址始终按协议规则处理。

## 10. 标签页菜单

标签页右键菜单采用现代编辑器通用交互：

- 重命名；
- 复制；
- 关闭；
- 关闭其他；
- 关闭右侧；
- 调整顺序。

批量关闭前必须提示将影响的标签页数量。关闭标签页属于非破坏性的视图状态，
不进入撤销/重做栈；删除标签页及其数据才属于结构编辑。
