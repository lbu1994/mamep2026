# 共享界面设计

## 1. packages/ui

包含三端共享的：

- 页面布局；
- 顶部应用栏；
- 侧边栏；
- 标签页；
- 寄存器表（含多行选择、行级右键菜单、行级键盘快捷键，见 [ADR-015](adr/ADR-015-行编辑交互与剪贴板决策.md)）；
- 连接配置；
- 日志面板；
- 插件页面；
- 设置页面；
- 通用组件；
- 可访问性工具；
- UI Store。
