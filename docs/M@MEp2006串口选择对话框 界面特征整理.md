---

## 一、窗口整体结构

| 项目         | 特点                                                                 |
| ------------ | -------------------------------------------------------------------- |
| **窗口标题** | `M@MEp2006 Advance! [Set up Communication]`                          |
| **窗口性质** | 模态对话框（独立弹窗，非主界面内嵌），窗口尺寸固定，不可拖拽缩放     |
| **整体布局** | 上中下三段式：顶部品牌区 \+ 中部参数区（左右分栏） \+ 底部操作按钮区 |
| **视觉风格** | 经典 Windows 原生控件风格，灰色背景，标准下拉框 / 按钮，无扁平化设计 |

---

## 四、Communication（通信参数区 — 左栏）

| 参数项           | 控件类型 | 默认值 / 选项                          |
| ---------------- | -------- | -------------------------------------- |
| **Port**         | 下拉框   | `COM1`（自动枚举系统串口，非固定列表） |
| **Speed**        | 下拉框   | `9600`（波特率）                       |
| **Data Length**  | 下拉框   | `8 BIT`（数据位）                      |
| **Stop Bit**     | 下拉框   | `1 BIT`（停止位）                      |
| **Parity Bit**   | 下拉框   | `None`（校验位）                       |
| **Flow Control** | 下拉框   | `OFF`（流控）                          |

> 共 **6 项**串口基础参数，全部为下拉选择，无输入框。

---

## 五、Communication Option（通信选项区 — 右栏）

右栏分**左右两列**排布：

### 左列

| 参数项            | 控件类型 | 默认值                 |
| ----------------- | -------- | ---------------------- |
| **Slave Address** | 下拉框   | `31`（从站地址）       |
| **Rx Delay**      | 下拉框   | `5ms`（接收延迟）      |
| **Endian Type**   | 下拉框   | `Big Endian`（字节序） |
| **Read Verify**   | 下拉框   | `ON`（写后回读校验）   |
| **Retry Counter** | 下拉框   | `1`（重试次数）        |
| **Check Code**    | 下拉框   | `CRC-16`（校验方式）   |

### 右列

| 参数项             | 控件类型 | 默认值                   |
| ------------------ | -------- | ------------------------ |
| **Byte Acc\.Type** | 下拉框   | `Normal`（字节访问类型） |
| **Address Adjust** | 下拉框   | `ON`（地址调整）         |

> 共 **8 项**高级通信参数，大部分为下拉选择，仅 Retry Counter 是带微调按钮的数值输入框。

---

## 六、底部操作按钮区

| 按钮        | 样式                                      | 位置 |
| ----------- | ----------------------------------------- | ---- |
| **OFFLINE** | 立体凸起按钮，黑色粗体字                  | 左   |
| **ONLINE**  | 立体凸起按钮，蓝色粗体字（默认 / 主按钮） | 右   |

> 两个按钮尺寸一致，左右对称分布，ONLINE 为连接动作的主操作。

**点击 ONLINE 后行为**：连接成功则关闭对话框回到主界面；连接失败也关闭对话框，主界面图标提示处于 OFFLINE 状态。

---

## 七、设计细节与交互特点

1. **分组清晰**：所有参数用横线 \+ 标签分组（User Information / Communication / Communication Option），视觉边界明确

2. **标签左对齐**：所有参数标签左对齐，控件右对齐，整齐统一

3. **全下拉优先**：几乎所有参数都是下拉选择而非自由输入，从源头避免非法参数输入，降低误操作风险，符合工业软件严谨风格

4. **参数密度高**：单窗口内集中了 14 项通信相关参数，无需多步跳转，一次配置完成

5. **连接状态切换**：底部 OFFLINE/ONLINE 双按钮，直观体现当前连接状态并支持一键切换

6. **授权信息前置**：User Information 放在显眼位置，体现软件授权 / 用户身份管理机制
