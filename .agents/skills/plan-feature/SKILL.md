# 新功能开发

本 Skill 是 Mamep2026 新功能开发的 Codex 显式入口。用户提供的功能描述位于调用参数中；缺失时先询问。

1. 完整读取 [dev-workflow](../dev-workflow/SKILL.md)，遵守其中的开发判断、项目约束和测试时机。
2. 将本次任务视为开发任务，从「需求澄清」开始，不得跳过澄清直接改代码。
3. 输出《需求澄清清单》后暂停，等待用户确认。
4. 确认后输出实施计划并暂停，等待用户明确回复「计划通过」。
5. 计划通过后按共享工作流完成文档、代码、测试和回归；每一步仍遵守用户对测试执行的授权。

范围只限当前功能请求，不顺带重构、清理或处理无关文件。
